# Формат timeline.json

Один файл на ролик – всё, что меняется без правки кода: размер, длительность, тексты голоса и субтитров,
стыки сцен, QR. Читают его `build_page.py` (→ `data.js`, `window.TL`), `render.py`, `tts.py`, `audio.py`, `qa.py`.

```json
{
  "title": "Цифровой СИЗ",          // название страницы и отчёта QA
  "w": 1080, "h": 1920,            // 9:16 для телефона и мессенджеров; 1920×1080 для экрана и YouTube
  "fps": 60,
  "dur": 50.0,                     // секунды; кадров будет ровно dur × fps
  "qr_url": "https://t.me/...",    // пусто – QR не строится; иначе window.QR – матрица для M.drawQR
  "qr_check_t": 47.0,              // секунда, на которой qa.py читает QR из готового файла
  "cuts": [6.3, 16.0, 19.5, 33.0, 41.2],   // стыки сцен – qa.py строит по ним плотные листы кадров
  "webfonts": true,                // подключить Inter с Google Fonts (на машине без Inter)
  "fonts": ["800 100px \"Inter Display\"", "600 40px Inter"],   // что дождаться до первого кадра
  "vo": [                          // фразы голоса: id, начало в секундах, текст для TTS
    {"id": 1, "t": 0.5, "text": "Сколько касок, курток и перчаток сейчас на руках у ваших людей?"}
  ],
  "subs": [                        // субтитры: начало, конец, текст (цифрами, с неразрывными пробелами)
    [0.5, 3.4, "Сколько касок, курток и перчаток сейчас на руках у ваших людей?"]
  ]
}
```

## Правила
- **Голос и субтитры – разные поля.** В `vo.text` числа словами («ста пятидесяти тысяч»), так TTS читает
  без ошибок; в `subs` – цифрами («150 тысяч»).
- **Неразрывный пробел** (U+00A0) в субтитрах между числом и единицей и в коротких связках:
  «150 тысяч», «90 суток», «у кого», «и ИТ» – иначе перенос рвёт смысл.
- **Окна субтитров не пересекаются:** конец одного ≤ начало следующего. Движок гасит субтитр к концу его окна.
- **После `tts.py`** сверь `audio/vo_durations.json` с окнами: фраза должна кончиться минимум за 0.2 с до
  следующей. Не влезает – сдвинь тайминги сцен или сократи текст, а не ускоряй голос.
- **Длинное тире «—» запрещено** во всех текстах; только «–» и дефис. После двоеточия и тире – строчная буква.
- Комментарии `//` выше – только для этой справки, в настоящем JSON их нет.
