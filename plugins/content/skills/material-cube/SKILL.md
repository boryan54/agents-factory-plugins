# Пакет артикула отделки для 3D-куба

Покупатель держит в руках одну плитку и не видит, как выглядит комната целиком. Пакет
артикула закрывает это: материал в 4–6 реальных комнатах, снятых так, что комната совпадает
с коробкой куба и уходит вглубь. Каталог на кубе показывает пакет по артикулу или штрих-коду.

Работает **только вместе со скиллом `cube-video`**: оттуда механика Genosai, лупы, замеры,
промпт-книга и гейты. Здесь – то, что добавляет артикул.

Справка:
- комнаты, типы материалов, раскладки – [references/rooms.json](references/rooms.json);
- каркас промпта комнаты и почему он такой – [references/prompt-room.md](references/prompt-room.md);
- пакеты, папки, смета, приёмка, контракт manifest.json – [references/package.md](references/package.md);
- шаблон карточки – [sku.template.json](sku.template.json).

Скрипт: `scripts/material_cube.py`, все фазы умеют `--dry-run`.

## Шаги

### 0. Промпт-книга и стиль
Прочитай `ПРОМПТ-КНИГА.md` проекта целиком (как в `cube-video`). Найди `style.json` рядом
с папками артикулов: в нём правила, утверждённые на эталоне стиля, уже в виде текста
промпта (`room_add`, `hero_add`, `motion_add`, `video_model`). Нет `style.json` – этот
артикул становится эталоном, гейты идут в полном составе.

### 1. Карточка артикула
Папка `артикулы/<артикул>/`, в ней `фото/` и `sku.json` по шаблону. Тип материала, формат
в мм, финиш, раскладка, шов – из данных заказчика. `material_en` – одна фраза о том, что
видно на фото. Не выдумывай характеристик, которых нет на фото и в данных.

### 2. План и смета
```bash
python <скилл>/scripts/material_cube.py plan --sku артикулы/<артикул> -v
```
Покажи заказчику список комнат и смету. Гейт: явное «ок».

### 3. Кадры
```bash
python <скилл>/scripts/material_cube.py stills --sku артикулы/<артикул> --dry-run
python <скилл>/scripts/material_cube.py stills --sku артикулы/<артикул>
python <скилл>/scripts/material_cube.py sheet  --sku артикулы/<артикул>
python <скилл-cube-video>/scripts/cube_stats.py артикулы/<артикул>/stills/*.png
```

### 4. ГЕЙТ сходства – по каждой комнате
Покажи `sheet.jpg`: фото заказчика рядом со всеми кадрами. Вопрос по каждой комнате:
материал тот же – цвет, рисунок, масштаб? Ответ записывается:
```bash
python <скилл>/scripts/material_cube.py approve --sku ... --ok hero,bath_wall --reject living_floor --note "плитка мельче, чем в жизни"
```
Замечание -> правило в промпт-книгу; если правило для всех артикулов – в `style.json`.
Затем `stills --only <брак> --force`.

### 5. Лупы (пакеты standard и premium)
Модель выбирает заказчик (гейт 2 `cube-video`) один раз на эталоне, она пишется
в `style.json`. `loops --dry-run`, затем `loops`, затем замер `cube_stats.py loops/*.mp4`.

### 6. Выгрузка
```bash
python <скилл>/scripts/material_cube.py manifest --sku артикулы/<артикул> --by <кто принял>
```
В манифест попадают только принятые комнаты. Папка артикула целиком уходит в каталог.

### 7. Пакетный режим
После утверждённого эталона (`style.json` есть):
```bash
python <скилл>/scripts/material_cube.py batch --root артикулы --phase plan
python <скилл>/scripts/material_cube.py batch --root артикулы --phase stills --dry-run
python <скилл>/scripts/material_cube.py batch --root артикулы --phase stills
python <скилл>/scripts/material_cube.py batch --root артикулы --phase sheet
```
Гейт сходства по каждому артикулу остаётся: пакетом гонятся траты, а не приёмка.

## Критерии (✅ / ❌)

- ✅ На каждом кадре материал совпадает с фото заказчика по цвету, рисунку и масштабу
- ✅ Комната фронтальная, с одной точкой схода, пол и стены уходят вглубь
- ✅ Светлый кадр без крупных тёмных зон; материал – главное, обстановка нейтральная
- ✅ Материал только на целевой поверхности; остальные поверхности нейтральные
- ✅ Каждая комната прошла гейт сходства с записью в `sku.json`
- ✅ Лупы 2160x3840, замкнуты пинг-понгом, проверены `cube_stats.py`
- ✅ `manifest.json` есть только у принятых артикулов, факт-смета в кредитах посчитана
- ❌ Материал «красивее, чем в жизни»: другой оттенок, придуманные прожилки, другой финиш
- ❌ Неверный масштаб: плитка 60x120 размером с ладонь, доска шириной с дверь
- ❌ Тот же материал на всех поверхностях комнаты; вторая отделка на целевой поверхности
- ❌ Люди, текст, логотипы, слова про витрину и `cabinet` в промпте, движущаяся камера
- ❌ Пакетный прогон без утверждённого эталона стиля; выгрузка без приёмки
