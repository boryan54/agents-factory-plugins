# Пакет артикула: состав, папки, смета, выгрузка в каталог

## Папка артикула

```
артикулы/<артикул>/
  sku.json          карточка: что за материал, формат, раскладка, пакет
  фото/             всё, что прислал заказчик (jpg/png/webp), лучшие кадры первыми
  plan.json         промпты и смета (делает `plan`, руками не править)
  results.json      кэш задач и фактические траты (делает скрипт)
  stills/           hero.png и <комната>.png, 9:16
  clips/            сырые клипы
  loops/            готовые лупы под куб, 2160x3840
  sheet.jpg         контактный лист для приёмки: фото заказчика | комнаты
  manifest.json     выгрузка в каталог куба (только после приёмки)
```

Шаблон карточки – [../sku.template.json](../sku.template.json).

## Пресеты пакета

| Пакет | Что внутри | Кредитов, оценка |
|---|---|---|
| `base` | hero-кадр + 4 комнаты, статика 4K | ~75 |
| `standard` | `base` + луп hero + лупы 2 комнат | ~220 |
| `premium` | `base` + лупы hero и всех комнат | ~320 |

Оценка по ценам: кадр chatgpt-image-2 4K – 16 (факт 2026-07-18), 2K – 10;
клип grok-imagine-1.5 1080p 6 сек – 48 (факт 2026-08-21). Точная смета – `plan`,
факт – `status`. Апскейл, лупы, контактный лист – ffmpeg, ноль кредитов.
Перегенерация забракованной комнаты – ещё 16.

Музыка на артикул не нужна: каталог на кубе играет одну общую подложку.

## Приёмка: два уровня

1. **Эталон стиля – один раз на заказчика.** Первый артикул проходит все гейты
   `cube-video`: кадры, модель, видео. Утверждённые правки уходят в промпт-книгу
   проекта. Дальше этот стиль – закон для всех артикулов этого заказчика.
2. **Сходство – на каждый артикул.** Человек смотрит `sheet.jpg` (фото заказчика
   рядом с каждой комнатой) и отвечает по каждой комнате: да / нет + замечание.
   Цена ошибки здесь – возвраты и претензии покупателей: на картинке материал
   должен быть тем, что лежит на полке, а не красивее.

Пакетный режим (`batch`) разрешён только после пункта 1.

## manifest.json – контракт с каталогом куба

```json
{
  "schema": 1,
  "sku": "18456732",
  "barcode": "4600000000000",
  "name": "Керамогранит Оникс Мэджик Браун 60x120 полированный",
  "type": "porcelain_xl",
  "format_mm": [600, 1200],
  "finish": "полированный",
  "hero": {"image": "stills/hero.png", "loop": "loops/hero.mp4"},
  "rooms": [
    {"id": "bath_wall", "title": "Ванная – стены",
     "image": "stills/bath_wall.png", "loop": "loops/bath_wall.mp4"}
  ],
  "qc": {"by": "Boris", "date": "2026-10-30"},
  "credits": 218,
  "generated": "2026-10-30"
}
```

Цены и остатки в манифест не пишем: они живые и приходят в каталог из фида заказчика.
Пути относительные к папке артикула: каталог забирает папку целиком.
