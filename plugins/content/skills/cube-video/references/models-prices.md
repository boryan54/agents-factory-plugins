Цены **замерены на живом API 21.08.2026** полем `cost` из `taskInfo`. Каталожные цены
из `GET /v1/models` отличаются: они даны для старших разрешений. Верить только замеру.

## API

- Хост `https://api.genosai.io`, заголовок `Authorization: Bearer <ключ>`.
- Ключ – только из `.secrets/genosai.env` (`GENOSAI_API_KEY=sdk_live_...`). В чат не выводить.
- `GET /v1/balance` -> `{total, main, bonus}`.
- `POST /v1/createTask` `{"model": ..., "input": {...}}` -> `data.taskId`.
- `GET /v1/taskInfo?taskId=...` -> `data.status`, `data.result.media_urls[]`, `data.cost`.
- `POST /v1/uploads` (multipart `file`) -> url. **Ответ разбирать как `(resp.get("data") or resp).get("url")`** –
  обёртка `data` есть не всегда, слепой разбор даёт 400 на следующем шаге.
- `GET /v1/models` отдаёт список **без обёртки `data`** – единственный такой эндпоинт.

### Грабли окружения (Windows)
- Без `certifi` системный python валится на `CERTIFICATE_VERIFY_FAILED`.
  В скриптах контекст строится как `ssl.create_default_context(cafile=certifi.where())`.
  Если запускаешь что-то своё – ставь `SSL_CERT_FILE=certifi.where()`.
- Заголовок `Connection: close` лечит `SSLEOFError` на длинных сессиях.
- ffmpeg лежит в установке WinGet: `%LOCALAPPDATA%\Microsoft\WinGet\Packages\Gyan.FFmpeg_*\ffmpeg-9.0-full_build\bin\`.
  Скрипты находят его сами, либо задай `CUBE_FFMPEG`.

### Параметры видеомоделей
`prompt`, `aspect_ratio` (`9:16`), `resolution` (`720p` | `1080p` | `4k`, «k» строчная),
`duration` – **строка** (`"6"`, `"8"`), `image_urls` – первый url = стартовый кадр.

### Коды ошибок
401 – не тот хост или ключ. 402 – кончились кредиты. 400 – сверить параметры с этим файлом
(чаще всего: `duration` числом вместо строки, `4K` вместо `4k`, неподдерживаемое разрешение модели).
