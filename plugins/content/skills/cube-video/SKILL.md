# Ролик для 3D-куба: 9:16, светлый фон, замкнутый луп

3D-куб – большой прозрачный ЖК-экран с сильной внутренней подсветкой. Объект в нём
выглядит висящим в воздухе. Объём даёт **тень** на заднюю стенку и на пол, а не чернота фона.

Три вещи, которые отличают куб от обычного вертикального ролика:
**светлый фон** (замер 18 эталонов: 109–225 из 255, чёрных пикселей 0–3.7%),
**стационарный свет** и **бесшовный луп** – ролик крутится в витрине весь день.

Каркас промпта, три запрета и постановка света – [references/prompt-frame.md](references/prompt-frame.md).
Модели, замеренные цены и API – [references/models-prices.md](references/models-prices.md).
Метрики и опорные замеры – [references/metrics.md](references/metrics.md).
Механизм промпт-книги – [references/prompt-book.md](references/prompt-book.md).
Разбор 24 референсов и чужие сценарии – [references/etalony.md](references/etalony.md).

Ключ API – только из `.secrets/genosai.env`, в чате не спрашивать и не показывать.

## Шаги

### 0. Промпт-книга – ПЕРВОЕ действие
Найди `ПРОМПТ-КНИГА.md` в папке проекта и **прочитай целиком**. Нет файла – заведи по
шаблону из `references/prompt-book.md`. Все её правила применяются ко всем промптам ниже.
Это делается перед каждой генерацией, включая повторную.

### 1. Бриф
Что за объект и откуда он: фото товара заказчика, генерация с нуля по описанию, готовая
3D-модель или человек/персонаж. Что должно происходить за 15–20 секунд. Какой куб
(диагональ, разрешение, ориентация). Фон: белый, светло-серый или цветной под бренд.

### 2. Стартовый кадр – дёшево и первым
Собери промпт по каркасу: БАЗА + СВЕТ + СЦЕНА + ОБЪЕКТ. Один-два варианта композиции,
`chatgpt-image-2`, `9:16`, `2K` – 10 кредитов за вариант.
```bash
python <скилл>/scripts/cube_gen.py frame --project project.json --dry-run   # смета и промпты
python <скилл>/scripts/cube_gen.py frame --project project.json             # после «ок»
python <скилл>/scripts/cube_stats.py frames/*.png
```

### 3. ГЕЙТ 1 – приёмка кадра
Покажи файлы и замер. Жди явного «ок». Замечание -> правило в промпт-книгу -> перегенерация.
Кадр стоит 10 кредитов, клип – в 3–5 раз дороже: спорные места чинятся здесь.

### 4. ГЕЙТ 2 – выбор модели по ценнику
Покажи таблицу моделей с ценами (`python <скилл>/scripts/cube_gen.py models`), смету ролика
и остаток на балансе. **Модель выбирает заказчик.** Дефолт – `grok-imagine-1.5`;
seedance по умолчанию не предлагать, при заказе на 1080p предупредить о переплате.
Тест движения гонится в 720p, старшие разрешения – только для финала.

### 5. Клип и луп
Оживи кадр (`start_frame` обязателен), замерь, замкни луп пинг-понгом.
Пинг-понг бесплатно удваивает длительность: 6 сек генерации -> 12 сек лупа,
8 сек -> 16 сек, что и есть целевые 15–20.
```bash
python <скилл>/scripts/cube_gen.py video --project project.json
python <скилл>/scripts/cube_loop.py clips/clip.mp4 -o loop.mp4
python <скилл>/scripts/cube_stats.py clips/clip.mp4 loop.mp4
```

### 6. ГЕЙТ 3 – приёмка видео
Покажи луп, замер и фактические траты. Замечание -> правило в промпт-книгу -> повтор.
Три перегенерации подряд означают, что дело не в промпте, а в композиции: возвращайся к шагу 2.

### 7. Финал и сдача
Музыка (`suno-v5.5`, `instrumental: true`, 16 кредитов, приходят 2 трека), апскейл
до родного кадра куба, сведение:
```bash
python <скилл>/scripts/cube_loop.py clips/clip.mp4 -o final.mp4 \
    --upscale 2160x3840 --music audio/music.mp3 --volume 0.22 --crf 16
python <скилл>/scripts/cube_gen.py status --project project.json    # факт-смета
```
Апскейл деталей не добавляет, но кубу нужен родной размер: иначе плеер витрины
масштабирует сам и делает это хуже.

### 8. Верни опыт
Что сломалось, что сработало, новые цены и модели – в `feedback.md` рядом со скиллом.
Работаешь в чужом проекте, где фабрики нет, – это делает постуха через `report.md`.

## Критерии (✅ / ❌)

- ✅ Фон >= 90 по замеру, чёрных пикселей <= 5% – светлый фон, а не «стильная чернота»
- ✅ Ровно один объект в кадре, свет стационарен, тень уходит от зрителя вглубь
- ✅ Дрейф тени <= 2.0, лупΔ финала <= 3 – проверено `cube_stats.py`, а не на глаз
- ✅ 9:16, 15–20 сек, бесшовный луп, музыка, родное разрешение куба
- ✅ Все три гейта пройдены с явным «ок»; каждое замечание записано в промпт-книгу
- ✅ Промпт-книга прочитана перед КАЖДОЙ генерацией
- ❌ Чёрный фон; два объекта; упоминание витрины, стекла, showcase, cabinet в промпте
- ❌ Качающаяся или вращающаяся тень; движущаяся камера
- ❌ Луп «на глаз», без замера; сдача сырого клипа без склейки
- ❌ Платная фаза без выбора модели заказчиком; seedance по умолчанию
- ❌ Дым, дымка, световые лучи, текст в кадре, рамки

## Эталон (реальный, замеры воспроизводимы)

Вход: «телефон, парит, светлый фон, спокойное движение».
Кадр `J_grey_backshadow.png` – БАЗА + СВЕТ + `Seamless neutral light-grey studio cyclorama,
slightly darker floor than wall` + телефон `floating just above a low matte podium cube`.
Замер: фон 137.0, чёрное 0.1%, тень 58.5% – объём есть, фон светлый.

Оживление тем же промптом движения тремя моделями (6 сек):

```
клип        фон    чёрное  тень   дрейфX  лупΔ
grok       136.2    0.1%   47.6%   1.25    5.1
seedance   133.2    0.1%   61.6%   0.35    0.6   (но 450 кредитов на 1080p)
veo-lite   136.9    0.0%   50.8%   1.10    3.3
```

Пинг-понг на клипе grok: лупΔ **5.1 -> 1.6**, длительность 6 -> 12 сек, ноль кредитов.
Кросс-фейд на том же материале: 5.3, то есть почти бесполезен.
