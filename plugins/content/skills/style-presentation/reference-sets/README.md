# Наборы фотореференсов

Каждый набор — это **отдельная папка** внутри `reference-sets/`. В папку кладёшь 1–3 картинки
готовых слайдов/макетов, которые задают стиль. Потом в чате говоришь Claude:
«сделай презентацию, используй набор **синие**» или «как в **курсе Антона Богатушина**».

## Как добавить новый набор
1. Создай папку: `reference-sets/<имя-слаг>/` (латиницей, через дефис, напр. `green-corporate`).
2. Положи туда картинки-референсы (`.png`/`.jpg`/`.jpeg`/`.webp`), 1–3 штуки.
3. (Необязательно, но удобно) создай рядом `set.json` — тогда выбор набора сразу подтянет и стиль:
   ```json
   {
     "name": "Синие",
     "aliases": ["синие", "синий", "blue", "голубые"],
     "accent_color": "1E5BD6",
     "style": "Профессиональный слайд 16:9 в едином корпоративном стиле как на референсе. ..."
   }
   ```
4. Допиши строку в `INDEX.md` (folder, название, алиасы, краткое описание стиля).

## Как набор попадает в презентацию
В `project.json` достаточно указать **одно поле**:
```json
"reference_set": "blue"
```
`gen_slides.py` сам найдёт папку `reference-sets/blue/`, заберёт все картинки из неё и
использует их как референсы. Поле `references` при этом можно не заполнять.

Приоритет:
- если задан `reference_set` — берутся картинки из этой папки;
- дополнительно к ним добавляются файлы из `references` (если они тоже указаны);
- если `reference_set` не задан — работает по-старому (только `references`).

`reference_set` может быть:
- **именем папки** (слагом) — ищется в `reference-sets/` внутри скилла: `"reference_set": "blue"`;
- **абсолютным путём** к любой папке с картинками: `"reference_set": "E:\\Claude\\my-refs"`.
