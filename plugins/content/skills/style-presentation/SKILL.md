# Презентации в фирменном стиле (Genosai)

Скилл отдела ПродКонтент. Полный цикл: разбор источника → структура слайдов → согласование →
генерация → визуальный QA → сборка PPTX/PDF.

## Ключ API (стандарт фабрики)
Основной вход – **BobGate** (свой шлюз: Genosai, Runware, OpenRouter с переключением при сбое).
Ключ `BOBGATE_API_KEY=bg_...` – в `~/.secrets/bobgate.env` (или `.secrets/bobgate.env` вверх по дереву).
Если BobGate не ответил, скрипт сам 5 минут работает через Genosai напрямую.
Ключ Genosai (запасной путь) – порядок поиска: переменная `GENOSAI_API_KEY` → поле `api_key_file` в project.json →
**`.secrets/genosai.env` в корне фабрики** (ищется автоматически вверх по дереву;
формат `export GENOSAI_API_KEY=sdk_live_...`).
**Ключ в чате не спрашивать, не показывать и не коммитить.** Нет ни одного файла с ключом — смотри
раздел «Веб-чат claude.ai» ниже: если подключён коннектор BobGate, работай через него; если нет — попроси
заказчика положить ключ или подключить коннектор.

## Веб-чат claude.ai — коннектор BobGate (нет ключа в `.secrets`)
В облачной песочнице claude.ai нет файлов ключей. Вместо `gen_slides.py` слайды рисует **коннектор BobGate**
(`https://bobgate.kupryakov.ru/mcp`, вход по паролю Бориса): инструменты `generate_image`, `task_status`,
`chat_text`, `balance`, `list_reference_sets`. Расход идёт по ключу «веб-чаты» с суточным лимитом.
Как понять, что этот режим: `py scripts/gen_slides.py` пишет «нет ключа», а в списке инструментов есть
`generate_image` от BobGate.
1. Структура и **гейт согласования** — как обычно, ни одной платной генерации до «ок».
2. Стиль: `list_reference_sets` — фирменные наборы уже лежат на BobGate (имена как в `reference-sets/`).
   Свой референс заказчика — только публичная ссылка в `image_urls`.
3. Смета: `balance` (остаток суточного лимита в рублях). Цена слайда 1K — около 3–6 ₽.
4. Генерация: на каждый слайд `generate_image` с `prompt` = `style` + `image_prompt`, `aspect_ratio` из
   project.json, `model` (по умолчанию `chatgpt-image-2`), `reference_set`. Ждёт до ~100 с; если статус не
   `succeeded` — `task_status` с `wait_seconds: 60`. Упал (`failed`) — повтори этот слайд, не весь дек.
5. Скачай слайды в песочницу: `python scripts/fetch_slides.py project.json 1=<ссылка> 2=<ссылка> …`
   (ссылки живут 72 часа). Песочница не пускает в интернет — попроси заказчика добавить
   `bobgate.kupryakov.ru` в claude.ai → Настройки → Возможности → разрешённые домены; до этого отдай ссылки
   на слайды списком.
6. QA и сборка — как в режиме A: `build_pptx.py`, `build_pdf.py`.

## Состав скилла
```
style-presentation/
├── SKILL.md
├── project.example.json          # шаблон конфига
├── scripts/fetch_slides.py       # веб-чат: скачать слайды по ссылкам BobGate в out_dir
├── reference-sets/               # именованные наборы стилей (INDEX.md — каталог)
└── scripts/
    ├── gen_slides.py             # генерация слайдов через Genosai (устойчив к 429/503, ретраи)
    ├── build_pptx.py             # сборка PPTX из картинок (python-pptx, БЕЗ node)
    ├── build_pdf.py              # сборка PDF из картинок (Pillow)
    └── text_slide_template.py    # РЕЖИМ B: шаблон редактируемого текстового слайда
```

## Зависимости
`python` + `pip install pillow python-pptx`; для чтения источников — `python-docx` (docx),
`pypdf` (pdf), `pymupdf` (рендер PDF-страниц в картинки, если нет текстового слоя).
Нужен исходящий интернет к `https://api.genosai.io`.

## Алгоритм (режим A — основной)
1. **Источник.** Прочитай вход: docx → `python-docx`; pdf → `pypdf` (текст) или `pymupdf`
   (если PDF без текстового слоя — рендерь страницы и читай глазами); md/txt — напрямую.
2. **Стиль.** Резолвь набор по имени из `reference-sets/INDEX.md` (напр. «Россия 2050 ЕАО»,
   «Вайбкодинг Антона Богатушина», «AI будущее black») либо прими присланные картинки-референсы.
   Не задан — спроси и перечисли доступные наборы.
3. **Структура → ЖЁСТКИЙ ГЕЙТ.** Покажи таблицу слайдов: № · заголовок · что на слайде ·
   что рассказывать · промпт картинки. **Генерация начинается ТОЛЬКО после явного «ок».**
   Это критично: генерация жжёт кредиты.
4. **project.json.** Скопируй `project.example.json`: `project_name`, `out_dir`, `model`
   (`chatgpt-image-2`), `aspect_ratio` (`16:9`), `accent_color`, `reference_set`, `style`,
   массив `slides` (num, title, on_slide, narration, image_prompt).
5. **Генерация:** `python scripts/gen_slides.py <project.json>` — запускай в фоне.
   Точечная перегенерация: `python scripts/gen_slides.py <project.json> N --force`.
6. **Визуальный QA (обязателен).** Просмотри КАЖДЫЙ `slide_NN.png`:
   - номер на бейдже = номер слайда;
   - **кириллица без искажений** — частая беда: склеенные буквы, латиница/греческие символы
     внутри русских слов, битые мелкие подписи внутри иллюстраций;
   - соответствие согласованным текстам, единый стиль.
   Нашёл дефект — перегенерируй точечно с усиленным промптом. При битом мелком тексте внутри
   картинки помогает прямой запрет: «внутри иллюстрации без текстовых подписей».
7. **Сборка:**
   ```
   python scripts/build_pptx.py <project.json>   # PPTX 16:9, картинки на всю площадь
   python scripts/build_pdf.py  <project.json>   # PDF
   ```

## Режим B — редактируемые текстовые слайды
Когда нужен живой правимый текст или точное повторение кеглей фирменного дека — собирай слайд
нативно из `scripts/text_slide_template.py` (python-pptx). Стиль снимается с образца:
шрифт/кегли/цвета читаются через python-pptx, слайд строится в ТОМ ЖЕ формате, что образец,
чтобы pt совпадали 1:1. Грабли (учтены в шаблоне): первый абзац авто-фигуры центрируется —
ставь `PP_ALIGN.LEFT`; висячий отступ — через `pPr marL/indent`.

## Режим C — гибрид
Genosai рисует ТОЛЬКО иллюстрацию (промпт «no text no labels no words», фон = сплошной цвет
дека, `reference_set` пустой), а текст кладётся нативно рядом через `add_picture()`.
Бесшовно только на однотонном фоне.

## Экономия кредитов
- Сначала структура и согласование, потом генерация.
- Перегенерируй точечно (`N --force`), а не весь дек.
- Следи за балансом: `GET /v1/balance` на `https://bobgate.kupryakov.ru` с ключом BobGate (остаток лимита в рублях).

## Критерии качества (✅ / ❌)
- ✅ Структура согласована заказчиком до единой платной генерации
- ✅ На каждом слайде номер бейджа = номер слайда
- ✅ Кириллица чистая: без склеенных букв, латиницы/греческих символов в русских словах, без битых мелких подписей внутри иллюстраций
- ✅ Тексты соответствуют согласованным, стиль единый по всему деку
- ✅ Собраны оба файла — PPTX (16:9) и PDF
- ❌ Битая кириллица или чужой символ в русском слове хоть на одном слайде
- ❌ Номер бейджа не совпадает с номером слайда
- ❌ Перегенерация всего дека из-за дефекта одного слайда (нужно `N --force`)

## Эталон слайда (вход → выход)
Вход — строка структуры: `№3 · «Удар до 36 кг» · на слайде: крупный план ударного механизма · рассказать: сила воздействия · промпт: изометрия устройства, teal-акцент, белый фон`.
Выход — `slide_03.png`: изометрическая иллюстрация в наборе стиля, бейдж «3», заголовок «Удар до 36 кг» чистой кириллицей, без текстовых подписей внутри картинки. QA пройден: бейдж=3, буквы целы, стиль совпадает с соседними слайдами.
