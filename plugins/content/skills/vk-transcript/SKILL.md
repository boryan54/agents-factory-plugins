# Расшифровка видео с ВК-Видео

Одно видео по ссылке → один MD-файл. Каскад: **берём то, что уже готово, и лезем в тяжёлое
только когда лёгкое не сработало.** Скрипты рядом со скиллом, зависимости — только `yt-dlp`
и `certifi`; всё остальное stdlib.

## Каскад уровней

| Ур. | Чем распознаём | Цена входа | Когда |
|---|---|---|---|
| **0** | готовые субтитры ВК (`yt-dlp`) | ~3 МБ, уже стоит | **всегда первым.** ВК заявляет покрытие ~90% роликов |
| **1** | `faster-whisper` `large-v3-turbo` + ffmpeg | ~3,6 ГБ, ставится по требованию | субтитров нет или качество не годится |
| **2** | WhisperX + pyannote `speaker-diarization-community-1` | ~7 ГБ + токен HF | **только по явному запросу «раздели по спикерам»** |

Рецепты установки уровней 1–2, план Б (`whisper.cpp`), опция GigaAM и разбор диагностик —
в [references/levels.md](references/levels.md). Ставить что-либо — **только с разрешения заказчика**.

## Шаги

1. **Нормализуй ссылку.** Понимаются `vk.com/video-X_Y`, `vkvideo.ru/video-X_Y`, `?z=video…`,
   эмбед `video_ext.php?oid=…&id=…`. Делает `vk_fetch.py` сам.
2. **Диагностика до работы** — `--probe`: название, автор, длительность, дата загрузки, главы,
   есть ли субтитры и сколько вариантов. Одна команда, ничего не качает:
   ```bash
   python <скилл>/scripts/vk_fetch.py "<ссылка>" --probe
   ```
   Доложи заказчику, каким уровнем пойдёшь. **`chapters` часто пустой** — на главы не рассчитывай.
3. **Уровень 0 — забор субтитров.** Пишет `<slug>.meta.json`, `<slug>.cues.json`, `<slug>.vtt`:
   ```bash
   python <скилл>/scripts/vk_fetch.py "<ссылка>" --out .work --slug <краткое-имя>
   ```
   Выход `2` = субтитров нет → уровень 1. Закрытое/возрастное видео → добавь
   `--cookies-from-browser chrome`.
4. **Сборка MD.** Шапка, оглавление по главам, склейка реплик в абзацы с таймкодами:
   ```bash
   python <скилл>/scripts/build_md.py --meta .work/<slug>.meta.json \
       --cues .work/<slug>.cues.json --out output/transcripts/<ГГГГ-ММ-ДД>-<имя>.md
   ```
   Путь по умолчанию — `output/transcripts/<ГГГГ-ММ-ДД>-<краткое-имя>.md` в проекте, куда позвали.
   **`<ГГГГ-ММ-ДД>` в имени файла — дата РАСШИФРОВКИ (сегодняшняя), а не дата загрузки видео.**
   Дата загрузки живёт в шапке файла, в имени её не дублируем: файлов из одного видео может быть
   несколько, а разбирают их по тому, когда сделали.
5. **Заполни «Кратко» и врезку о качестве.** Скрипт оставляет плашку-заглушку — саммари он
   не выдумывает. Прочитай собранный файл и замени плашку: 3–5 предложений о чём видео +
   5–9 тезисов. **Только то, что реально сказано.** Мусор распознавания — помечай, а не
   «додумывай». На уровне 0 скрипт ставит врезку «О качестве источника» с HTML-комментарием:
   впиши туда 3–5 конкретных искажений («интернациональность» вместо «интенциональность»),
   если они встретились, и убери комментарий.
6. **Отчёт в чат — без расшифровки.** Путь к файлу, метрики (реплик, слов, покрытие в ЧЧ:ММ:СС
   против длительности, чем распознано) и саммари. Десятки тысяч слов в чат не вываливаются.
7. **Верни опыт в фабрику.** Всё, что пошло не так — новый формат ссылки, сломавшийся ВК,
   провалы покрытия, качество субтитров, — идёт в `feedback.md` рядом со скиллом.
   **Если работаешь не на фабрике, а в чужом проекте, фабричного `feedback.md` под рукой нет:**
   пиши находку в отчёт постухи (`report.md` рядом с агентом), а на фабрику её переносит Boris
   по разделу «Как вернуть опыт на фабрику» в `agents/content/transcriber/README.md`.
   Нового механизма не выдумывать, файлы фабрики из чужого проекта не искать.

## Грабли ВК (в скриптах уже обойдены — не переписывай руками)

- **Нет корневых сертификатов** → первый же запрос падает с
  `[SSL: CERTIFICATE_VERIFY_FAILED]`. Лечение: `SSL_CERT_FILE = certifi.where()` в окружении.
- **CDN отдаёт HTTP 400** на скачивание VTT без заголовков → нужны `User-Agent`
  и `Referer: https://vkvideo.ru/` (берутся из `http_headers` в JSON yt-dlp).
- **ВК шлёт ДВА варианта `ru`, побайтно одинаковых** → дедуп по sha256, иначе текст удваивается.
- **Субтитры ВК РОЛЛОВЫЕ**: каждая реплика повторяет хвост предыдущей. Замерено на живом
  ролике: 29 872 слова сырых реплик против **9 997 уникальных** — без склейки по перекрытию
  текст утраивается. Самая дорогая грабля, ловится только сверкой, а не на глаз.
- **Реплики короткие** (5–8 слов) и почти никогда не кончаются на точке → абзацы режутся
  по предложениям, а не по репликам, иначе фразы рвутся пополам.
- **Точек ВК почти не ставит**: на замеренном ролике самый длинный период без точки — **266 слов**.
  Срабатывает страховка `hard=160`, и разрыв неизбежен. Чтобы он не приходился на середину
  придаточного, `build_md.py` откатывает точку разреза назад к ближайшей запятой (окно —
  до `hard//2`). Скрипт печатает, сколько таких разрывов было и сколько ушло на запятую.
- **`--write-subs` падает** с `unsafe file extension: 'ru.Ru AUTO'` (ВК шлёт title без точки)
  → VTT качаем сами по `subtitles.ru[0].url` из `-J --skip-download`.
- **`--write-auto-subs` не использовать никогда** — на ВК субтитры лежат в `subtitles`,
  а `automatic_captions` пустой.
- Окружение Windows: нет `ffmpeg`, `ffprobe`, `rg`, `jq`. Опора на Python stdlib и `yt-dlp`.

## Ограничения площадки (это не баг агента — так и говори)

- **Видео «только для подписчиков» не берётся даже с куками** (yt-dlp#17298).
- **Плейлисты и каналы целиком не обещаем** — обход каналов VK сломан (yt-dlp#16756).
- **ВК ломает yt-dlp примерно раз в квартал.** Порядок: обновить стабильный → попробовать
  nightly → вытащить прямой URL формата через `-J` → честно доложить, что сломалась площадка.

## Состав MD-файла

Шапка (название, автор/канал, длительность, дата загрузки, ссылка, дата расшифровки,
**чем распознано**, объём) · строка про спикеров · «Кратко» (саммари + тезисы) ·
«Главы» — если ВК их отдал · врезка «О качестве источника» на уровне 0 ·
«Расшифровка» абзацами с таймкодами.

**Врезку «О качестве источника» ставит сам `build_md.py`, когда движок — субтитры ВК.**
Качество автосубтитров среднее: термины, имена собственные и отчества искажаются
регулярно, смысл восстанавливается по контексту, но дословная цитата без сверки с видео
небезопасна. Врезку не удалять; конкретные примеры искажений дописывает агент.

**Типографика:** в сдаваемом файле длинного тире «—» быть не должно — ни в шапке, ни в
заглушках, ни в саммари (правило заказчика; en dash «–»). Скрипты это уже соблюдают.
Исключение одно — **тело расшифровки**: это дословный текст источника, его не правят.

**«Чем распознано» обязательно** — субтитры ВК, faster-whisper или whisperx. Это вопрос
доверия к тексту: у субтитров ВК бывают провалы, у ASR — свои. Читатель должен знать источник.
**Если работали субтитры ВК — честно писать, что разделения по спикерам нет.** Не расставлять
спикеров наугад.

## Критерии

✅ Каскад пройден снизу вверх, уровень выбран по факту, а не «сразу тяжёлым» ·
в шапке указано, чем распознано · таймкоды соответствуют исходнику ·
текст склеен без утроения (сверь: слов в MD ≈ слов на выходе `vk_fetch.py`) ·
**абзацы кончаются на границе предложения; там, где источник не поставил точку и сработал
принудительный разрыв сверхдлинного периода, абзац кончается на запятой — таких абзацев
единицы, и число их скрипт печатает** · саммари только из сказанного · на уровне 0 в файле
есть врезка о качестве субтитров · в чат ушли путь + метрики + саммари, а не расшифровка ·
спикеры либо размечены диаризацией, либо честно объявлены отсутствующими.

❌ Утроенный текст (не сработала склейка ролловых субтитров) · расшифровка вывалена в чат ·
дописано за спикера или «улучшен» смысл · спикеры проставлены наугад · в шапке не сказано,
чем распознано · **абзац оборван посреди слова или придаточного** (разрыв не откатился
к запятой) · длинное тире в шапке, заглушках или саммари · поставлено что-то тяжёлое без
разрешения заказчика · поломка площадки выдана за результат («видео пустое»).

## Эталон (реальный прогон)

Вход: `https://vkvideo.ru/video-12540819_456239028` — лекция 87 минут (01:27:10).
Выход: уровень 0, ASR не понадобился. 1938 реплик после склейки, **10 002 слова**,
покрытие 00:00:05 … 01:27:12, 91 абзац, глав нет, спикеры не размечены.
Принудительных разрывов сверхдлинных периодов — 4, все ушли на запятую;
самый длинный период без точки — 266 слов. Время работы — секунды.

**Размер файла — в БАЙТАХ, не в символах.** Выход `build_md.py` (с заглушкой саммари) —
**117 610 байт** (66 201 символ). Тот же файл после заполнения саммари и тезисов —
**121 870 байт** (~119 КБ). Кириллица в UTF-8 занимает 2 байта на знак: посчитаешь символы — эталон
занизится вдвое (было «~66 КБ»), и **задвоенный текст пройдёт за исправный**. Сверяй байты.

Сырьё в VTT: **3866 блоков** с таймкодами, из них 15 — побайтные повторы предыдущего блока,
то есть **3851 различная реплика**; слов соответственно 29 946 и 29 872 (повторы дают 74 слова).
После склейки перекрытий остаётся 1938 реплик и 10 002 слова: **две трети — ролловые повторы**.
