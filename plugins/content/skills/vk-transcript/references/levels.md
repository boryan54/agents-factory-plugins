# Уровни 1 и 2: локальный ASR и диаризация

Справка к `vk-transcript`. Читается **только когда уровень 0 (субтитры ВК) не закрыл задачу**.
Ничего из этого не ставится без явного разрешения заказчика: речь о гигабайтах.

## Уровень 1 — локальный ASR (~3,6 ГБ)

Когда: `vk_fetch.py` вернул код `2` («субтитров нет») либо заказчик посмотрел текст и сказал,
что качество не годится.

**Состав:** `ffmpeg` + `faster-whisper` + рантайм-библиотеки cuBLAS/cuDNN +
модель `large-v3-turbo` (формат CTranslate2, качается при первом запуске).

**Железо заказчика:** NVIDIA RTX 3060, **12 ГБ VRAM**, драйвер 591.86. `large-v3` влезает
свободно; час видео ≈ 2,5 минуты при батчевой обработке.

**Отдельный CUDA Toolkit НЕ нужен** — нужны только рантайм-библиотеки. Рецепт из README
faster-whisper с `LD_LIBRARY_PATH` линуксовый и **на Windows не работает**: библиотеки должны
лежать в каталоге, видимом загрузчику DLL (рядом с бинарём или в `PATH`).

**Типовая диагностика:** `Could not locate cudnn_ops64_9.dll` — не поставлены/не видны
библиотеки cuDNN. Не «сломался Python» и не «мало памяти».

Порядок работы уровня 1: `yt-dlp` тянет аудиодорожку (`-f bestaudio`) → `ffmpeg` в 16 кГц моно
WAV → `faster-whisper` с `language="ru"` → сегменты с временами приводятся к тому же формату
`cues.json`, что и на уровне 0 (`[{"start","end","text"}]`) → дальше обычный `build_md.py`
с `--engine "faster-whisper large-v3-turbo"`. Склейка ролловых повторов на этом уровне не нужна
(сегменты Whisper не перекрываются), но `build_md.py` её и не делает — она живёт в `vk_fetch.py`.

Две разницы в готовом файле по сравнению с уровнем 0. Первая: **врезку «О качестве источника»
`build_md.py` ставит только когда движок — субтитры ВК**; для ASR оговорку о качестве, если она
нужна, пишет агент своими словами (у Whisper другие типовые ошибки). Вторая: Whisper расставляет
пунктуацию, поэтому принудительные разрывы сверхдлинных периодов (`hard=160` с откатом к запятой)
почти не срабатывают — счётчик в выводе `build_md.py` должен быть близок к нулю. Если он большой,
значит модель отдала текст без точек: проверь `language="ru"` и параметры.

**План Б, если faster-whisper упрётся** (репозиторий заморожен с ноября 2025):
**whisper.cpp v1.9.2** — официальные готовые бинарники под Windows, лицензия MIT, Python вообще
не нужен. Выдаёт VTT/SRT напрямую — их разбирает `parse_vtt` из `vk_fetch.py`.

## Уровень 2 — диаризация (~7 ГБ, только по явному запросу)

Когда: заказчик прямо просит «раздели по спикерам», «кто что говорит».

**Состав:** WhisperX + pyannote `speaker-diarization-community-1`.
Нужен **токен HuggingFace** и однократное принятие условий на странице модели —
одобрение автоматическое, ждать человека не надо.

Автор WhisperX предупреждает прямым текстом: «Diarization is far from perfect». Границы реплик
поедут, особенно на перебивках и коротких вставках. **Так и докладывай заказчику**, а не
«размечено 4 спикера, готово».

Выход диаризации приводится к файлу `speakers.json`:
`[{"start": сек, "end": сек, "speaker": "SPEAKER_00"}, …]` — его понимает
`build_md.py --speakers`. Абзац рвётся на смене спикера, имя подставляется в заголовок абзаца.

Имена спикеров модель не знает — она даёт `SPEAKER_00`, `SPEAKER_01`. Заменять их на живые имена
можно **только если в самом видео прозвучало, кто есть кто**. Догадка по голосу — выдумка.

## Опция на будущее: GigaAM

**GigaAM** от SberDevices (MIT) — русская SOTA: ~3,3% WER против ~7,9% у Whisper,
пунктуация из коробки.

Минусы, из-за которых он не уровень 1 по умолчанию: проваливает **русско-английскую техническую
речь** (а это большая часть рабочих материалов) и требует `torch`. Разумен как уровень 1-бис для
чисто русской речи — лекции, интервью, совещания без терминов.

## Когда ВК ломает yt-dlp

Случается примерно **раз в квартал**. Порядок действий, по шагам, без самодеятельности:

1. Обновить стабильный: `python -m pip install -U yt-dlp`. Проверить `--version`
   (рабочая на момент проверки — `2026.07.04`).
2. Не помогло — nightly:
   `python -m pip install -U --pre "yt-dlp[default]"`.
3. Не помогло — вытащить прямой URL формата вручную: `-J --skip-download` и посмотреть
   `formats[].url`; иногда видео качается, даже когда экстрактор ошибается на метаданных.
4. Не помогло — **честно доложить, что сломалась площадка**, и приложить точный текст ошибки.
   Не выдавать пустой результат за расшифровку.

## Известные ограничения площадки

- **yt-dlp#17298** — видео «только для подписчиков» не берётся даже с куками.
- **yt-dlp#16756** — обход каналов VK сломан, поэтому каналы и плейлисты не обещаем.
- Возрастные ограничения, закрытые группы и «только для зарегистрированных» лечатся куками:
  `--cookies-from-browser chrome` (или `firefox`, `edge`). Браузер при этом лучше закрыть —
  иначе база кук может быть заблокирована.
