# Каталог штампов — куда скатывается AI-дизайн

Открывается на шаге 3 скилла `frontend-design`, когда план из четырёх токенов готов, но код ещё не написан. Задача — поймать себя на дефолте до того, как он застынет в вёрстке.

## Главный тест

Мысленно ответь на **похожий бриф** с нуля, ни на что не опираясь. Пришёл примерно туда же, куда пришёл сейчас? Значит, это не решение для этого заказчика, а то, что выдаётся по умолчанию на любой запрос такого сорта.

Проверяется только та ось, которую бриф оставил свободной. **Где бриф задаёт направление — его слова сильнее всего остального**, в том числе когда он просит ровно один из обликов ниже. Заказчик, попросивший кремовый фон с антиквой, получает кремовый фон с антиквой.

## Три облика, к которым сваливается AI прямо сейчас

1. **Кремовая антиква.** Тёплый кремовый фон (около `#F4F1EA`), контрастная антиква в заголовках, терракотовый акцент.
2. **Чёрное с кислотой.** Почти чёрный фон и единственный яркий акцент — кислотно-зелёный или вермильон.
3. **Газета.** Broadsheet-раскладка: волосяные линейки, нулевые скругления, плотные узкие колонки.

Каждый из них законен для какого-то брифа. Проблема в том, что они появляются **независимо от предмета** — это привычка, а не выбор. Если свободная ось привела в один из трёх, направление переделывается, и в сдаче называется, что именно поменялось и почему.

## Штампы помельче — по одному

| Штамп | Когда всё-таки можно |
|---|---|
| Большая цифра + мелкая подпись, три метрики в ряд, градиентный акцент на первом экране | цифра действительно главное, что есть у предмета, и она проверяемая |
| Маркеры `01 / 02 / 03` у пунктов | это настоящая последовательность: процесс, хронология, шаги, где порядок нужен читателю |
| Иконки в кружках у списка «преимуществ» | иконка добавляет узнавание, а не заполняет пустоту слева от текста |
| Стеклянная карточка с размытием поверх градиента | есть реальная глубина слоёв, а не один слой, притворяющийся тремя |
| Анимация «появление снизу» на каждом блоке при скролле | движение говорит что-то о предмете; один поставленный момент сильнее россыпи эффектов |
| Три колонки «Быстро / Надёжно / Выгодно» | за каждым словом стоит конкретика заказчика, а не обещание |
| Абстрактные 3D-шарики и сетки-градиенты как фон | предмет действительно про абстракцию, а не про лодки, склад или клинику |

Отдельно про движение: лишняя анимация — один из самых надёжных признаков «сделано нейросетью». Сначала решается, **должно ли** здесь что-то двигаться, и только потом — как.

## Что говорить при сдаче

Одна строка на каждое изменённое решение: **что было по умолчанию → что стало → почему для этого предмета**. Без этой строки заказчик видит просто другой вариант, а не работу.
