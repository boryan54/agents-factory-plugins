# 21st.dev — готовые компоненты в проект

[21st.dev](https://21st.dev/) — каталог UI, собранный дизайн-инженерами: React-компоненты, целые блоки и шаблоны, темы shadcn, шейдеры и градиенты. Всё на **React + Tailwind по соглашениям shadcn/ui**, код копируется в репозиторий, а не тянется зависимостью — значит его можно править под проект и он не тащит вес чужой библиотеки.

## Когда брать оттуда, а когда писать самому

**Брать:** типовые узлы, которые везде одинаковые и которые долго доводить руками — навигация с мобильным меню, аккордеон FAQ, карусель отзывов, тарифные карточки, диалоги, тосты, hero-секции со сложной анимацией, фоновые градиенты и шейдеры.

**Писать самому:** первый экран с оффером, блоки под конкретную фактуру заказчика, всё, что несёт signature-элемент дизайна. Если собрать сайт целиком из чужих блоков — получится ровно тот «шаблонный лендинг», которого стандарт требует избегать.

Правило: компонент из каталога — это заготовка, а не финал. Обязательно подгони под палитру, типографику и радиусы проекта.

## Как установить

Каталог работает через **shadcn CLI**. Сначала инициализация в проекте (один раз):

```bash
npx shadcn@latest init
```

Дальше любой компонент ставится по своему адресу из каталога:

```bash
npx shadcn@latest add "https://21st.dev/r/<автор>/<компонент>"
```

Адрес берётся на странице компонента — там же лежит готовая команда, её можно скопировать целиком. Компонент кладётся в `components/ui/` проекта вместе с зависимостями.

Альтернатива: на странице компонента есть **AI-ready промпт** — его можно вставить агенту, и тот встроит компонент в проект. Способ подходит, когда нужна адаптация под уже существующую структуру, а не чистая установка.

## Ограничения, о которых надо знать

- Просмотр каталога бесплатный, **бесплатных копий компонентов — 2 в день**; безлимит — по платной подписке. Планируй: не расходуй лимит на то, что быстрее написать руками.
- Компоненты рассчитаны на **React**. Если проект на Astro — либо подключай React-остров (`@astrojs/react`) точечно, либо переноси разметку и классы Tailwind руками, без рантайма React. Второе часто честнее: ради одного аккордеона тянуть React в статический лендинг — минус к скорости, а скорость у нас в жёстких требованиях.
- После установки **проверь вес**: компонент с тяжёлой анимационной библиотекой может съесть бюджет первого экрана. Не влезает в LCP — заменяй.
- Компонент проверь на доступность (фокус с клавиатуры, контраст) и на `prefers-reduced-motion` — в каталоге лежат разные по качеству работы.

## Проверка после установки

1. Компонент собрался, типы TypeScript не ругаются.
2. Палитра и шрифты — проектные, а не дефолтные из примера.
3. Мобильная версия не поехала.
4. Lighthouse после добавления не просел (особенно LCP и CLS).
