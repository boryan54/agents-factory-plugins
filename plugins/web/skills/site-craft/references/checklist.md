# Чек-лист перед сдачей сайта

Прогоняется целиком. Пункт не выполнен — сайт не сдаётся. На каждый измеримый пункт — **цифра или скриншот**, а не «сделано».

## Производительность (замер, не ощущение)

```bash
npx lighthouse <url> --view      # мобильный профиль с троттлингом 4G — дефолт Lighthouse
```

- [ ] LCP < 2.0 с (мобильный профиль, throttling 4G)
- [ ] INP < 200 мс
- [ ] CLS < 0.1
- [ ] Performance в зелёной зоне **на мобильном**, цифры показаны заказчику
- [ ] Все изображения в AVIF/WebP, с `srcset` и размерами; hero — `fetchpriority="high"`
- [ ] Шрифты self-hosted, ≤2 семейства, `font-display: swap`, кириллица в subset
- [ ] Сторонние скрипты отложены (`defer` или после интеракции)

## SEO

- [ ] Ровно один `h1` на странице, иерархия h2–h3 не нарушена
- [ ] Уникальные `title` (≤60) и `description` (≤160) на каждой странице
- [ ] JSON-LD валиден (проверить в валидаторе Schema.org)
- [ ] Open Graph и Twitter Cards с картинкой 1200×630 — превью проверено вживую
- [ ] `sitemap.xml` и `robots.txt` отдаются, канонические URL проставлены
- [ ] Favicon-пакет на месте
- [ ] Alt у всех значимых изображений
- [ ] ЧПУ короткие, латиницей
- [ ] Сайт готов к Яндекс.Вебмастеру и Search Console

## Конверсия

- [ ] Первый экран отвечает «кому / что / какая выгода» за 5 секунд
- [ ] CTA — глагол результата, а не «Отправить»
- [ ] **Заявка с формы реально дошла до адресата** (проверено боевой отправкой)
- [ ] UTM-метки долетают в заявку
- [ ] Валидация формы и понятное состояние после отправки
- [ ] Цели в Метрике и GA4 срабатывают (проверено, а не «настроено»)
- [ ] Sticky-CTA на мобильной версии
