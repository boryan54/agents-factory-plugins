# Журнал скилла — site-craft

Проколы, удачи и замечания из проектов. По накопленному скилл обновляется
(правка под конкретный прокол, а не переписывание целиком).

Формат записи:
```
### <YYYY-MM-DD> · <проект> · [+ удача | - прокол | ? замечание]
Что произошло. Что сработало/не сработало. Предложение к правке скилла.
Источник: <постуха агента / Boris / Аргус>
```

### 2026-07-30 · приёмка мастер-промпта · ? замечание
Исходный документ заказчика обрывается на пункте 6 («Финальный чек перед
сдачей — прогони по чек-») — самого чек-листа в нём нет. Чек-лист собран
заново из требований документа плюс то, чего в нём не было: боевая проверка
доставки заявки, правовой минимум РФ (политика, чекбокс согласия, реквизиты),
запуск axe. Если у заказчика найдётся оригинальный хвост документа — сверить.
Источник: Гефест
