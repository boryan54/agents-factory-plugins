# Журнал скилла — post-craft

Проколы, удачи и замечания из проектов. По накопленному скилл обновляется
(правка под конкретный прокол, а не переписывание целиком).

Сюда же стекается статистика постов: тема, тип хука, время выхода, реакции
против медианы канала. Накопится 20–30 записей — станет видно, какие хуки и
рубрики реально работают у этой аудитории, и стилевой гайд уточняется по
фактам, а не по ощущениям.

Формат записи:
```
### <YYYY-MM-DD> · <канал> · <тема> · [+ удача | - прокол | ? замечание]
Хук: <тип>. Реакции: N (медиана канала M). Что сработало/не сработало.
Источник: <постуха агента / Boris / автозамер>
```
