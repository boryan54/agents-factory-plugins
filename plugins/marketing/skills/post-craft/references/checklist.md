# Проверка поста перед показом автору

Прогоняется целиком на гейте 3, до предпросмотра. Пункт не выполнен — пост не показывается как готовый.

## Технические — иначе не отправится

- [ ] Текст сообщения ≤ **4096** знаков (или подпись к фото ≤ **1024**)
- [ ] HTML-разметка парная: каждый `<b>`, `<i>`, `<a>` закрыт. Незакрытый тег роняет весь пост
- [ ] Внутри текста нет «голых» `<` и `>`, которые Telegram примет за тег
- [ ] Ссылки рабочие, ведут туда, куда обещают
- [ ] URL картинки открывается публично

## Содержание — иначе стыдно

- [ ] **Вся фактура от автора.** Ни одного выдуманного кейса, числа, имени или цитаты
- [ ] Хук — тот, что выбрал автор, а не первый вариант
- [ ] Ни одного клише из анти-паттернов стилевого гайда («в этом посте я расскажу», «сегодня поговорим о»)
- [ ] Одна мысль на абзац, нет простыни без воздуха
- [ ] Длина в пределах медианы канала ±30%
- [ ] Финал в манере автора, а не дежурное «подписывайтесь»

## Повторы — иначе аудитория заметит

- [ ] **Про это уже не писали.** Сверься со свайп-файлом и последними 20 постами
- [ ] Хук не повторяет приём двух предыдущих постов подряд
- [ ] Если это продолжение серии — есть отсылка к предыдущей части

## Картинка

- [ ] Соответствует утверждённому тексту, а не первоначальной идее
- [ ] Без текста и надписей внутри
- [ ] Читается в маленьком превью
- [ ] Пропорции и стиль — как принято в канале

## Публикация

- [ ] Предпросмотр показан **точно** в том виде, в каком выйдет
- [ ] Автор сказал явное «публикуй» или «в расписание на <время>»
- [ ] Для расписания: время выбрано по лучшим окнам из аудита, дата подтверждена
- [ ] Автор предупреждён, что по расписанию пост уйдёт **без повторного подтверждения**

## После выхода

- [ ] `message_id` сохранён — без него ни правки, ни закрепа, ни сбора реакций
- [ ] Пост записан в архив канала (тема, хук, рубрика, время)
- [ ] Через 24–48 ч снять реакции и сравнить с медианой канала, запись в журнал
