# Шаблон итогового Word-отчёта аудита

Собирается скиллом `docx` (anthropic-skills:docx). Имя файла: `audit-direct-<клиент>-<ГГГГ-ММ-ДД>.docx`. Шрифты безопасные (Calibri). Отдать пользователю кликабельной `file://`-ссылкой + блок «Файлы».

Три признака сильного отчёта (не отдавать без них):
1. Каждая находка доказана цифрами/скриншотом и посчитана в ₽/мес.
2. Одностраничное резюме для руководителя – читается без остального документа.
3. Заканчивается фазовым планом с метриками успеха, а не списком замечаний.

## Структура документа

### 1. Титульный лист
- «Аудит рекламных кампаний Яндекс Директ»
- Клиент / сайт / кабинет (логин)
- Период данных: ДД.ММ.ГГГГ – ДД.ММ.ГГГГ; модель атрибуции
- Дата отчёта
- Внизу: **{Имя} · {Агентство}** (из `~/.dirik/profile.md`)

### 2. Резюме для руководителя (строго 1 страница)
- Общая оценка кабинета: X/100 + светофор.
- Текущие показатели vs KPI: расход, лиды/продажи, CPA/ДРР факт против цели.
- Топ-3 проблемы – каждая одной строкой с ценой: «Мусорные площадки РСЯ съедают ~74 000 ₽/мес без единой продажи».
- Суммарная оценка потерь ₽/мес и прогноз эффекта от исправлений (консервативно/реалистично).
- Одно главное действие недели.
Простой язык, без терминов – это единственная страница, которую гарантированно читает ЛПР.

### 3. Методология и вводные (0,5–1 стр.)
KPI из брифа и расчёт целевого CPA/ДРР (с формулой и допущениями); источники данных (Директ, Метрика, CRM, коллтрекинг); что не входило в скоуп (нет доступа к CRM и т.п.).

### 4. Оценка по блокам (1 разворот)
Таблица-светофор с оценкой каждого блока (🟢/🟡/🔴 + балл) и одной строкой сути:
| Блок | Оценка | Главное |
|---|---|---|
| Аналитика и цели | 🔴 25/100 | Стратегии учатся на ложной цели |
| Структура аккаунта | 🟡 60/100 | Бренд не выделен |
| Настройки кампаний | … | |
| Поиск: семантика и объявления | … | |
| РСЯ / ЕПК / Мастер кампаний | … | |
| Автостратегии и ставки | … | |
| Срезы (гео/пол/возраст/устройства) | … | |
| Посадочные и обработка лидов | … | |

### 5. Находки (ядро отчёта)
Сгруппировать: 🔴 Критично → 🟡 Важно → 🟢 Рекомендации. Внутри группы – по убыванию ₽. Каждая находка – карточка единого формата:

> **№N. [Название проблемы]** – 🔴 критично
> **Что происходит:** факт с цифрами из кабинета (+скриншот, если делали).
> **Где:** кампании/группы/URL.
> **Цена бездействия:** ~NN NNN ₽/мес (логика расчёта одной строкой).
> **Что сделать:** конкретное действие («добавить 47 минус-фраз из приложения Б», не «улучшить минусовку»).
> **Трудоёмкость:** 15 мин / 2 часа / отдельный проект.

### 6. Точки роста
Отдельно от ошибок: сегменты с CPA ниже среднего и недокупленным трафиком, отсутствующие типы кампаний, неохваченная семантика, регионы с долей показов ниже доли спроса. Каждая – с оценкой потенциала в ₽/мес.

### 7. Прогноз эффекта
Таблица: показатель → сейчас → после внедрения критичного (консервативно) → после всего плана (реалистично). Привязка к конкретным находкам, не «станет лучше».

### 8. План внедрения 30-60-90
- **Дни 1–30 (быстрые победы):** минус-фразы, отключение сливающих площадок/фраз/сегментов, починка целей, message match топ-кампаний, SLA 5 минут.
- **Дни 31–60:** пересборка структуры, корректировки по срезам, формы/скорость посадочных, ретаргетинг-сегменты, офлайн-конверсии.
- **Дни 61–90:** сквозная аналитика до оплат, гиперсегментация, A/B-тесты, масштабирование лучших сегментов.
По каждой фазе: ответственный, срок, метрика успеха. В конце: рекомендация повторного среза через месяц после внедрения.

### 9. Приложения
Полные таблицы: минус-фразы к добавлению, площадки к запрету, срезы из Мастера отчётов, список всех корректировок с вердиктами. Сырые выгрузки – отдельными файлами рядом с отчётом, в документ не вшивать.

### 10. Финальная страница
> Аудит подготовлен: **{Имя}**
> Агентство **{Агентство}**
> Дата: ДД.ММ.ГГГГ
>
> По вопросам внедрения рекомендаций – готовы взять работы на себя: [контакт из брифа/по умолчанию t.me/bogatushinai]

## Чек-лист перед отправкой
- [ ] Резюме помещается на 1 страницу и читается без остального отчёта
- [ ] У каждой критичной находки есть цена в ₽/мес и конкретное действие
- [ ] Сумма потерь в резюме = сумме по карточкам
- [ ] Оценки в светофоре согласуются с находками (нет 🟢 у блока с критичной находкой)
- [ ] План 30-60-90 покрывает все критичные и важные находки
- [ ] Подпись «{Имя} · {Агентство}» из профиля на титуле и финальной странице
- [ ] Документ открывается, таблицы не разъехались, файл отдан file://-ссылкой
