# Нормативы и пороги для аудита Яндекс Директа

Сводная шпаргалка всех числовых порогов. Источники: eLama, ppc.world, Rivox, Calltouch, Ingate, Kinetica, vc.ru, справка Яндекса. Пороги – ориентиры экспертов, не догма: всегда сверяй с экономикой конкретного бизнеса.

## Обучение автостратегий
| Параметр | Норматив |
|---|---|
| Конверсий в неделю на стратегию | ≥10 (и ~200 кликов) – минимум; >20 – оптимум; <10 – «Обучение остановлено» |
| Недельный бюджет | ≥10×tCPA (минимум Яндекса), норма ≥20×tCPA |
| Срок обучения | 1–2 недели; не судить МК/автостратегии раньше 2–4 недель |
| Пауза кампании | >7 дней = переобучение с нуля |
| Изменения настроек | ≤1 раза в 1–2 недели, шаг 10–20% |
| Снижение tCPA | по 10–20% в неделю; старт в 1,5–2× выше плановой |
| Окно конверсии (оплата за конверсии) | 21 день (и окно загрузки офлайн-конверсий) |
| Расход в день при оплате за клики | ≤35% недельного бюджета; ставка ≤10% недельного бюджета |
| Корреляция микроцели с макроцелью | ≥0,7 (использовать); <0,5 (запрещено) |
| Составная цель | до 10 условий «ИЛИ»; без звонков и офлайн |
| Целей на счётчик Метрики | до 200 |

## Поиск
| Параметр | Норматив |
|---|---|
| Минус-фразы | 100–500+ на поиске; 50–100 в РСЯ (больше – режет охват) |
| Мусорные запросы в нечищеных кампаниях | 20–60% расхода – считать в ₽, это главная цифра аудита |
| Чистка «Поисковых запросов» | старт: раз в 1–3 дня; зрелые: еженедельно (отчёт хранит 180 дней) |
| Автотаргетинг | только «Целевые» (± «Узкие»); после смены мест показа категории включаются сами |
| Объявлений на группу | 2–3 |
| Ключей на группу | 10–20 (не SKAG) |
| Быстрые ссылки | 8 с описаниями (иначе нет расширенных трафаретов; потеря 3–7% кликов) |
| «Мало показов» | НЧ-хвост = ~0,4% кликов, но ~3% дохода |
| Дубли ключей | до +34% к стоимости заказа |
| Звонки с контактов организации (бывш. визитка) | 20–30% всех звонков с рекламы |

## РСЯ / ретаргетинг
| Параметр | Норматив |
|---|---|
| CTR РСЯ | норма 0,5–1%; >5% при 30+ кликах = скликивание; <0,1% = плохой креатив |
| Отказы площадки | >35–40% при 20+ кликах = мусор (ретаргетинг: >25–30%) |
| Расход площадки без конверсий | ≥2×tCPA → запретить |
| Чистка площадок | еженедельно; старт – ежедневно |
| Лимит запрещённых площадок | 1000/кампанию (сплит десктоп+мобайл = 2000) |
| Сегмент ретаргетинга | ≥150–200 человек |
| Окно ретаргетинга | ритейл 7–10 дн; сложные 14–30; B2B до 540 |
| Частота показов | ориентир 5–7/нед; >50/мес = преследование (cap только в медийке, ≤4–5/день) |
| Ставки ретаргетинга | ~30% от поисковых; корзина +20%, просмотр −30% |
| CR ретаргетинга | 2–3% норма |
| Качественные лиды из РСЯ | закладывать ~50% от плана (фрод) |

## Срезы и корректировки
| Параметр | Норматив |
|---|---|
| Минимум данных для решения по сегменту | 100+ кликов (5–50 кликов = шум); формальный тест – от 250–350 конверсий на сегмент |
| Деление кампаний по гео | при различии CPC/CR ≥25%; Мск/СПб всегда отдельно |
| Диапазоны корректировок | гео −90…+1200% (только кампания); пол/возраст, устройства, платёжеспособность, аудитории −100…+1200%; время 0–200% (ручные стратегии) |
| «Младше 18» | −100% (типовой слив); но корректировка группы перекрывает кампанийную! |
| Новая корректировка | вводить с половины расчётной; формула (цель/факт − 1)×100 |
| Минимум показа по времени | 8 часов в неделю |
| Наблюдение | полными неделями, 10–14 дней минимум |

## Посадочные и пост-клик
| Параметр | Норматив |
|---|---|
| Отказы по фразе/кампании | >50% = провал message match |
| LCP | ≤2,5 с (загрузка ≤3–5 с), приоритет mobile |
| CR формы | до ~10%; CR e-com транзакций 0,2–3%; квиз 9–18% |
| SLA первого контакта | ≤5 минут (×5–10 к сделке); >30 мин = чинить в первую очередь |
| Конверсия лид→контакт | ≥70–80% |

## Экономика и отчёт
| Параметр | Норматив |
|---|---|
| Период данных аудита | 3–6 мес (минимум 30 дней или 2–3 цикла сделки) |
| Лаг покупки | учитывать (в кейсах до 19 дней); не судить последние 1–2 недели |
| Тесты новинок | 8–10% бюджета |
| Сигнал масштабирования | CPL сегмента в 2× ниже среднего + недокупленный трафик |
| Сигнал проблемы | срез с CPL в 2× выше среднего при сравнимом расходе |
| Минимальная выборка для CPA/CR | ~800–1000 переходов |
| Регулярность аудита | базовый – ежемесячно; глубокий – квартал/перед сезоном; экстренный – 48 ч при резком отклонении |
| Рыночная цена ручного аудита | 5 000–80 000 ₽ (топы от 50 000 ₽), 8–40 часов |

## Формулы
- `CR = конверсии / клики × 100%`; `CPA = расход / конверсии`; `ДРР = расход / выручка × 100%`; `ROMI = (прибыль − расход) / расход × 100%`
- `tCPA = чек × маржа × доля на рекламу` | `tCPA = CR(заявка→оплата) × прибыль сделки × (1 − желаемая маржа)` | `CACmax = LTV × (1 − маржа)`
- `ДРР целевой = маржинальность − желаемая прибыль` (минус эквайринг/логистика/налог)
- `ДРР цели = CPA / ценность конверсии × 100%`; сплит ценности: N микро → 1 макро ценностью V: макро V/2, микро V/(2N)
- Потери находки: `расход сегмента без конверсий × (30 / дней периода)` или `(CPAфакт − CPAцель) × конверсий/мес`
