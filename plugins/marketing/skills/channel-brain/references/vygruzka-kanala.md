# 02 — Как выгрузить любой Telegram-канал в файл

Выгрузка — штатная функция Telegram. Работает только в **Telegram Desktop**
(компьютерная программа с telegram.org/desktop; версия из Microsoft Store /
App Store может не иметь экспорта — тогда поставьте версию с сайта).
С телефона выгрузить нельзя.

## Пошагово

1. Откройте в Telegram Desktop нужный канал — свой или любой публичный.
2. Три точки в правом верхнем углу → **«Экспорт истории чата»**.
3. Настройки экспорта — три важных решения:
   - **Снимите галочки** с фото, видео, стикеров и файлов. Нужен только
     текст: без медиа экспорт занимает минуту, с медиа — часы и гигабайты.
   - **Формат: JSON** (машиночитаемый). Это критично — скилл разбирает
     именно JSON. Если выбрать HTML, придётся переэкспортировать.
   - **Период.** Каналу меньше 5 лет — берите всё. Старше — последние
     2–3 года: древние посты размывают картину.
4. Нажмите «Экспортировать». Прогресс-бар добежит — появится кнопка
   «Показать данные»: откроется папка вида `ChatExport_...`, внутри —
   файл **`result.json`**. Это и есть весь канал в одном файле.

## Что с ним делать

Отдайте файл своему ИИ с одной из команд:

- «Проанализируй вот этот Telegram канал» — аудит (свой канал) или разбор
  конкурента (чужой);
- «Извлеки стиль автора» — гайд по голосу;
- «Сделай из этого канала персональный стиль-скилл» — режим «установка»;
- «Идеи из моего канала», «собери свайп-файл», «сравни каналы» — остальные
  режимы (полный список — в `skill/channel-brain/SKILL.md`).

## Частые вопросы

**Это законно — выгружать чужой канал?** Экспорт отдаёт только то, что
автор сам опубликовал публично. Скилл работает с публичным контентом
и по своим правилам не тащит в отчёты персональные данные. Используйте
разборы для обучения приёмам, а не для копирования текстов дословно.

**У меня выгрузился только messages.html.** На шаге 3 был выбран формат
HTML. Повторите экспорт и выберите JSON.

**Канал огромный, файл на десятки мегабайт.** Нормально: скилл читает его
не целиком, а через парсер и выборки. Но если экспорт тянется часами —
вы забыли снять галочки с медиа (шаг 3).
