# Разведка рынка — два режима

Собрать фактуру о рынке и свести её в отчёт, по которому можно принимать решения. Ценность не в объёме собранного, а в трёх ответах: где деньги (сегменты), где пусто (свободные ниши), где конкуренты слабы (упаковка).

## Источник истины
- **Бриф проекта** — ниша, регион, площадки, папка отчётов. Не задан — спроси, не выдумывай.
- **Предыдущие отчёты** в папке отчётов — для сравнения «что изменилось».
- Ключ платного сборщика — `.secrets/firecrawl.env`. В чат не выводить, в git не коммитить.

## Чем собирать
1. **По умолчанию — встроенные WebSearch и WebFetch.** Их хватает для режима «Тренды» и для общей картины рынка. Начинай с них: бесплатно и без настройки.
2. **Firecrawl (опционально)** — когда нужен структурный сбор с досок объявлений и каталогов, которые отдают обычному запросу заглушку. Настройка и безопасное хранение ключа — `references/nastroyka-firecrawl.md`.
3. Площадка не отдалась ни тем, ни другим — это факт для отчёта, а не повод придумать данные.

## Режим «Конкуренты»
Запрос вида «собери конкурентов в нише [ниша] на [площадка] по региону [регион]».

1. Собери 15–30 реальных предложений (доски объявлений, каталоги, сайты, карты).
2. По каждому зафиксируй: название · цена · что входит · есть ли фото/видео/отзывы · чем выделяется (или честное «ничем»).
3. Сведи в отчёт четыре секции: **ценовые сегменты** (эконом/средний/премиум + средний чек и «чем берут») · **свободные ниши** (где предложений мало или нет) · **слабая упаковка** (без фото, без отзывов, шаблонные тексты — список «где мы можем выиграть») · **выводы** (3–5 действий).
4. Сохрани файлом в папку отчётов, пришли резюме на 5–10 строк.

Формат — строго как в `references/primer-otcheta-konkurenty.md`. Открой эталон перед сборкой отчёта: с образцом перед глазами структура получается с первого раза.

## Режим «Тренды»
Запрос вида «собери темы недели по [тема]».

1. Пройди 2–3 источника, где аудитория обсуждает тему **текстом** (форумы, тематические сообщества, отзовики, комментарии).
2. Отбирай темы **по количеству обсуждений, а не по лайкам**: дискуссия = резонанс, лайк = пролистнули.
3. По каждой из топ-5 тем: почему обсуждают (боль / страх / желание) · 1–2 цитаты живым языком аудитории · идея контента.
4. Есть отчёт прошлого периода — добавь сравнение: что новое, что усилилось, что затухло.
5. Сохрани файлом, пришли резюме.

## Правила
- Каждая цифра — с источником: ссылка или площадка + дата сбора.
- Данных мало или доступ закрыт — так и напиши. Пробелы догадками не заполняются.
- Ниша задана широко («мебель») — сузь до «ниша + регион + площадка», иначе отчёт получится ни о чём.
- Не больше 100 платных запросов на задачу без согласования.
- Цитаты аудитории — дословно. Пересказ своими словами убивает главную ценность режима «Тренды».

## Критерии результата
✅ Все четыре секции на месте · резюме из 3 строк читается за 10 секунд · у каждой цифры источник · выводы сформулированы как действия («собрать оффер под студии», «открыть цены») · собрано ≥15 предложений или честно указано, почему меньше.
❌ «Рынок конкурентный» вместо вывода · цены «примерно» без ссылок · свободные ниши, выведенные из головы, а не из отсутствия предложений · пересказанные вместо цитат реплики аудитории · отчёт-простыня без секций.
