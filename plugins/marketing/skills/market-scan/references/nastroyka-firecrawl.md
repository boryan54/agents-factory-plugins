# Firecrawl — подключение и хранение ключа

Firecrawl читает сайты за агента: площадка видит обычный запрос, а не бота, поэтому доски объявлений и каталоги отдают содержимое, а не заглушку. Нужен **только** для структурного сбора с таких площадок. Темы аудитории, форумы, отзовики и общая картина рынка собираются встроенными WebSearch/WebFetch бесплатно — начинай всегда с них.

## Шаг 1. Ключ

1. Зарегистрируйся на `firecrawl.dev`, в личном кабинете открой **API Keys**, скопируй ключ (строка вида `fc-...`).
2. Есть бесплатный тариф с месячным лимитом запросов — актуальные цифры смотри на сайте, они меняются.
3. Положи ключ в файл `.secrets/firecrawl.env` в корне фабрики:

```
FIRECRAWL_API_KEY=fc-...
```

**Ключ вставляет заказчик сам, в файл, на своей машине.** Агент ключ не спрашивает, в чат не выводит и не печатает в логах: чаты и логи хранятся. Папка `.secrets/` в `.gitignore` — в репозиторий ключ не уедет.

## Шаг 2. MCP-сервер

Firecrawl подключается как MCP-сервер — файл `.mcp.json` в корне проекта:

```json
{
  "mcpServers": {
    "firecrawl": {
      "command": "npx",
      "args": ["-y", "firecrawl-mcp"],
      "env": { "FIRECRAWL_API_KEY": "${FIRECRAWL_API_KEY}" }
    }
  }
}
```

Ключ здесь **подставляется из переменной окружения**, а не пишется текстом: `.mcp.json` — обычный файл проекта, он попадает в git, и вписанный в него ключ утечёт вместе с репозиторием.

Переменную надо поднять перед запуском Claude Code — в PowerShell:

```powershell
Get-Content .secrets\firecrawl.env | ForEach-Object {
  if ($_ -match '^\s*([^#=]+)=(.*)$') { [Environment]::SetEnvironmentVariable($matches[1].Trim(), $matches[2].Trim(), 'Process') }
}
```

Подстановка `${...}` не сработала (старая версия клиента) — впиши ключ в `.mcp.json` напрямую **и сразу добавь `.mcp.json` в `.gitignore`**. Иначе не надо.

## Шаг 3. Проверка

1. Перезапусти Claude Code, выполни `/mcp` — сервер `firecrawl` должен быть в списке как подключённый.
2. Там же посмотри **точные имена инструментов** (вида `mcp__firecrawl__firecrawl_scrape`, `mcp__firecrawl__firecrawl_search` — состав зависит от версии пакета).
3. Эти имена допиши в строку `tools:` инструкции агента `market-analyst.md` — иначе агент их не увидит, даже когда сервер подключён.
4. Боевая проверка: попроси прочитать главную `firecrawl.dev` и показать первые строки. Вернулся текст — работает.

## Если не подключилось

Не воюй с настройкой: режим «Тренды» и общая картина рынка полностью работают на WebSearch/WebFetch. Без Firecrawl упрётся только структурный парсинг досок объявлений — тогда собирай меньше предложений вручную и честно указывай в отчёте, сколько площадок оказалось закрыто.

## Расход

Лимит — не больше 100 запросов на одну задачу без согласования с заказчиком. Кончился месячный лимит — это сигнал, что навык окупается; но сначала проверь, не тратятся ли запросы впустую (повторные заходы на одну страницу, сбор того, что уже есть в прошлом отчёте).
