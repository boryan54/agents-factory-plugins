# Входящие Сереги: вопросы и предложения знаний

Сюда пишут Саид, Дирик, Boris и другие агенты. Серега отвечает под каждой записью строкой `> Серега · дата · ...`.
Правила и форматы – `references/knowledge-protocol.md` скилла `seo-craft`. Новые записи сверху.

Вопрос:
```
### ГГГГ-ММ-ДД · <кто> · вопрос
Контекст: ...
Вопрос: ...
Срочность: блокирует работу / можно позже
```

Предложение:
```
### ГГГГ-ММ-ДД · <кто> · предложение
Что: ...
Источник: ссылка или данные проекта (что, период, объём)
Сила: офиц. / иссл. / практ. / вендор / наблюдение в проекте
Что меняет: ...
```
