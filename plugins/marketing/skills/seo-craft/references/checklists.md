# Принципы, шаблоны и чек-листы

> Справочник скилла `seo-craft` · редакция базы 2026-11-24 · полный отчёт и исходные заметки: `docs/research/seo-2026/` фабрики.
> Пометки силы доказательств: [офиц.] – Яндекс/Google, [иссл.] – исследование, [практ.] – практики, [вендор] – материал продавца сервиса.

### Десять принципов

1. Цель по Яндексу – топ-5 органики по ключевым кластерам; это одновременно условие цитирования в Алисе AI.
2. Один кластер – один интент – одна страница; кластеры помечаются флагами «интент», «геозависимость», «есть ИИ-ответ».
3. Приоритет контента: коммерческие посадочные и листинги → «какой выбрать», сравнения, подборки → калькуляторы и инструменты → гайды и FAQ в нейро-формате со ссылками на коммерческие страницы.
4. ИИ пишет черновик, человек отвечает за факты, цифры, обещания и решение о публикации; детерминированные данные (частотность, позиции, краулинг) берутся только из API и никогда не придумываются.
5. Каждая страница содержит фактуру, которой нет у LLM: цены, характеристики, кейсы, фото, цитату эксперта с должностью, дату обновления.
6. Факты о бренде (название, адреса, телефоны, цены, характеристики) одинаковы на сайте, в картах, справочниках, маркетплейсах и публикациях.
7. Внешние упоминания на площадках, которые цитирует ИИ, планируются как отдельный канал, а не как «ссылки».
8. KPI – пирамида: лиды и выручка → трафик по сегментам → видимость и SoV в Алисе AI → техника; позиции – диагностика.
9. Никаких накруток ПФ, отзывов, PBN, массовой аренды анкорных ссылок и сырой массовой генерации; если клиент настаивает, риски фиксируются письменно.
10. Любая платная публикация с коммерческим посылом – реклама с ERID; аналитика и формы – только на российской инфраструктуре.

### Старт проекта: доступы и аудит

- [ ] получить доступы: Яндекс Вебмастер (роль Редактор), Метрика, Google Search Console, Яндекс Бизнес, 2ГИС, CMS, хостинг, Bing Webmaster Tools;
- [ ] выгрузить из Вебмастера «Страницы в поиске → Исключённые», ошибки индексации, регион, главное зеркало, отчёт «Видимость сайта в Алисе AI»;
- [ ] выгрузить из GSC покрытие, эффективность с фильтром брендовых запросов, ручные меры; помнить о баге с завышенными показами май 2025 – апрель 2026;
- [ ] прокраулить сайт (SiteAnalyzer, Screaming Frog или свой краулер): дубли, canonical, коды ответа, глубина, пустые фильтры, JS-контент;
- [ ] проверить robots.txt и правила WAF/CDN на блокировку поисковых ИИ-ботов;
- [ ] снять, что ИИ уже говорит о бренде: Алиса AI, GigaChat, ChatGPT, Perplexity, DeepSeek, Google AI Mode на 20–50 фиксированных вопросах (бренд, категория, «какой поставщик выбрать», «жалобы на»);
- [ ] проверить правовую базу: счётчики и формы, согласия на ПД, русский язык интерфейса, реквизиты, маркировку прошлых публикаций.

### robots.txt для максимальной видимости

Шаблон (решение по обучающим ботам принимает клиент; на видимость в поиске этих систем, по официальной документации, оно не влияет; итог проверять в анализаторе robots.txt Вебмастера):

```
User-agent: Yandex
Disallow: /search/
Disallow: /cart/
Disallow: /*?sort=

User-agent: YandexAdditional
Disallow: /search/
Disallow: /cart/

User-agent: YandexAdditionalBot
Disallow: /search/
Disallow: /cart/

User-agent: OAI-SearchBot
Allow: /

User-agent: PerplexityBot
Allow: /

User-agent: Claude-SearchBot
Allow: /

# Только если клиент решил не отдавать контент для обучения моделей:
# User-agent: GPTBot
# Disallow: /
# User-agent: ClaudeBot
# Disallow: /
# User-agent: Google-Extended
# Disallow: /

User-agent: *
Disallow: /search/
Disallow: /cart/

Clean-param: sort&view&from /catalog/

Sitemap: https://example.ru/sitemap.xml
```

- [ ] группа `User-agent: Yandex` полностью дублирует нужные запреты, потому что при её наличии группа `*` для Яндекса игнорируется;
- [ ] Googlebot не ограничивать: AIO и AI Mode управляются только им и директивами сниппетов;
- [ ] сайт закрыт от ИИ-ответов только по явному решению клиента (Disallow для YandexAdditionalBot, nosnippet для Google).

### Семантика и кластеризация

- [ ] спрос: Wordstat API или выгрузки нового Wordstat по нужному региону и устройствам, с операторами и проверкой сезонности;
- [ ] конкурентная семантика: Keys.so или SpyWords по 3–5 видимым конкурентам и маркетплейсам;
- [ ] кластеризация по топ-10: порог 3–4 общих URL для инфо, 4–6 для коммерции, тест порога на 5–10% ядра;
- [ ] коммерческость: менее 35% – инфо, 35–60% – смешанный (делить), от 60% – коммерческий;
- [ ] для каждого кластера: интент, геозависимость, тип ответа в выдаче (сайты, Товары, карты, видео, ИИ-ответ), целевой URL, Title, H1, H2, бриф;
- [ ] инфо-темы переформулировать в «выборные» под этап выбора B2B-клиента;
- [ ] фильтровые и теговые страницы создавать только при спросе в регионе и достаточном числе товаров, остальное – noindex или canonical на родителя.

### Шаблон ТЗ

- [ ] URL, Title (формулировка вопроса или запроса в начале), H1, Description;
- [ ] интент и тип страницы, 2–3 конкурента того же типа, исключая бренды с type-in трафиком и сайты с накрученными ПФ;
- [ ] структура H2/H3 из топа и «Похожих» запросов Wordstat, с подвопросами под query fan-out;
- [ ] ключи с формой и числом вхождений по зонам, тематические слова (не менее 50% из топа);
- [ ] объём – диапазон по медиане топ-3 ±10%;
- [ ] обязательные блоки: прямой ответ, таблица параметров или сравнения, FAQ, цифры с источником, цитата эксперта, CTA на коммерческую страницу;
- [ ] фактура от заказчика: цены, характеристики, кейсы, фото, сертификаты;
- [ ] критерии приёмки: «Тургенев» 0–4 (5–7 только после ревью), уникальность, факт-чек каждой цифры, даты и нормы.

### Шаблон страницы под Алису AI и AI Overviews

- [ ] title и H1 повторяют вопрос пользователя;
- [ ] первый абзац – прямой ответ в 2–4 предложениях;
- [ ] самодостаточные разделы H2 под смежные подвопросы;
- [ ] таблица с параметрами, ценами или сравнением;
- [ ] конкретные цифры со ссылкой на первоисточник, цитата эксперта с должностью;
- [ ] автор, дата обновления, блок «Источники»;
- [ ] FAQ в конце, разметка Article, Organization, Person, BreadcrumbList (как структура, а не как «фактор»);
- [ ] внутренние ссылки на коммерческие страницы, без коммерческих блоков, перегружающих инфо-страницу;
- [ ] важный контент текстом в HTML, не в картинке и не только через JS.

### Приёмка ИИ-текста

- [ ] черновик сделан по ТЗ, а не «по теме»;
- [ ] добавлена фактура, которой нет у модели, и удалены общие места;
- [ ] каждая цифра, дата, норма и характеристика проверена по источнику;
- [ ] пройден чек-лист маркеров «ИИ-стиля» и «Тургенев»;
- [ ] тон бренда проверен человеком на первых 2–3 итерациях нового клиента;
- [ ] подпись автора-эксперта, блок источников;
- [ ] страница поставлена на мониторинг позиций на 4–8 месяцев.

### Технический чек-лист

- [ ] HTTPS, главное зеркало, 301 со всех вариантов, выбор зеркала в Вебмастере;
- [ ] robots.txt по шаблону выше, Clean-param вместо Disallow для параметров;
- [ ] автоматический sitemap.xml, IndexNow, «Переобход» и «Мониторинг важных страниц» для ключевых URL, обход счётчиком Метрики;
- [ ] canonical на листингах и фильтрах, noindex для поиска, сортировок, пустых фильтров;
- [ ] SSR или пререндер для JS-сайтов, рендеринг в Вебмастере отключён при SSR, проверка `YandexRotorSettings` и `history.back()`;
- [ ] CWV на мобильных: LCP ≤ 2,5 с, INP ≤ 200 мс, CLS ≤ 0,1;
- [ ] разметка Organization, LocalBusiness, Product/Offer, BreadcrumbList, Article, VideoObject, проверка в валидаторах, соответствие видимому тексту;
- [ ] фид в Яндекс Товары с актуальными ценами и наличием;
- [ ] регион в Вебмастере совпадает с Яндекс Бизнесом; региональные поддомены только с местными контактами, филиалом и уникальным контентом;
- [ ] еженедельный разбор «Исключённых страниц» и ошибок индексации.

### Внесайтовый план для B2B-продукта

- [ ] карточки в Яндекс Бизнесе и 2ГИС с полным NAP, фото, услугами, ответами на отзывы (для синей галочки 2ГИС – минимум треть за полгода);
- [ ] сбор отзывов от реальных клиентов через QR, чеки, письма после внедрения;
- [ ] экспертные кейсы и статьи на vc.ru и Habr, канал на Дзене, сообщество VK и VK Видео, Telegram-канал;
- [ ] присутствие на маркетплейсах и Авито для товарных позиций;
- [ ] отраслевые СМИ, каталоги поставщиков, рейтинги, партнёрские кейсы, экспертные комментарии;
- [ ] ссылки – брендовые и безанкорные; платные в Google – с rel="sponsored";
- [ ] ежемесячная проверка, что ИИ-ассистенты говорят о бренде, и исправление источников устаревших фактов.

### Правовой чек-лист

- [ ] платная публикация с коммерческим посылом – ERID через ОРД, пометка «Реклама», указание рекламодателя;
- [ ] никакой рекламы в Instagram, Facebook и на заблокированных ресурсах, никакой рекламы VPN и инструкций по обходу блокировок;
- [ ] Яндекс Метрика или российские аналоги вместо GA и GTM; убрать или согласовать с юристом reCAPTCHA, Google Forms, иностранные пиксели;
- [ ] отдельный неотмеченный чекбокс согласия на ПД, не объединённый с офертой; политика ПД; уведомление РКН;
- [ ] интерфейс на русском (кнопки, баннеры, разделы, формы) с 01.03.2026;
- [ ] реквизиты продавца, оферта, условия доставки, оплаты и возврата, ссылки на реестр сертификатов для товаров с обязательной сертификацией;
- [ ] вход на сайт без иностранной почты и аккаунтов;
- [ ] спорные случаи – к юристу; агент не даёт юридических заключений.

### KPI и отчётность

- [ ] ежемесячно: лиды и выручка из органики, трафик по сегментам (инфо, коммерция, бренд), конверсии ИИ-сегмента Метрики;
- [ ] еженедельно: позиции топ-3, топ-5, топ-10 по кластерам, SoV в Алисе AI из Вебмастера, ИИ-видимость по фиксированному набору промптов, брендовый спрос в Wordstat;
- [ ] сигнал тревоги: стабильные позиции и падающий CTR, рост «Исключённых страниц», падение SoV, аномалии ПФ (возможная атака накруткой);
- [ ] прогноз: частотность × CTR по позиции × поправка 15–40% на ИИ-ответ для инфо-кластеров, с пометкой, что поправка экспертная;
- [ ] клиенту обещаются фазовые результаты (3–6 месяцев – НЧ и СЧ, 6–9 – ВЧ и первые конверсии, 9–12 – ROI), а не «топ за месяц».

### Календарь

- [ ] после каждого core-апдейта Google: анализ не раньше чем через неделю после завершения, с поправкой на сезонность;
- [ ] ежеквартально: ревизия страниц с падающим CTR, обновление дат, цифр, цен и примеров;
- [ ] раз в полгода: пересбор семантики и проверка изменений robots.txt у ИИ-платформ, обновление правового чек-листа.
