# Чек-лист запуска кампании (ЕПК, 2026)

## До запуска

**Бриф и экономика** (`brief-and-economics.md`)
- [ ] Посчитаны допустимая цена заявки и целевой CPA (или ДРР)
- [ ] Недельный бюджет кампании ≥ 10 × целевой CPA, или честно выбрана более частая цель обучения
- [ ] Бюджет пересчитан без НДС

**Аналитика**
- [ ] Счётчик Метрики на всех страницах, доступ Директа к счётчику
- [ ] Цель = реальная заявка; проверена тестовой заявкой с компьютера и телефона; срабатывает один раз
- [ ] Цель сверена с базой заявок за прошлую неделю (если сайт уже работал)
- [ ] Звонки: коллтрекинг или цель «звонок»; офлайн-конверсии из CRM, если есть

**Структура**
- [ ] Каждой кампании хватит бюджета на 10 конверсий в неделю; иначе – меньше кампаний
- [ ] Поиск и РСЯ разнесены, если бюджет позволяет
- [ ] Регионы – только целевые; расширенный геотаргетинг – осознанно
- [ ] Расписание – под обработку заявок (0 % в часы, когда никто не отвечает)

**Семантика и автотаргетинг**
- [ ] Группы по смыслу, 5–15 фраз, заголовок группы конкретный
- [ ] Автотаргетинг: «целевые» + «свой бренд»; для групп из API категории сужены и перечитаны
- [ ] Минус-фразы: только проверенные на нишу, без пересечений с ключами

**Объявления**
- [ ] 2–3 комбинаторных объявления в группе (лимит – 3), каждое: 7 заголовков, 3 текста, картинки
- [ ] Картинки для РСЯ: 1:1 + 16:9 + 3:4, подпись ≤ 5 слов, в центре, ≤ 20 % площади; A/B – две картинки
- [ ] Цены и акции совпадают с сайтом; нет обещаний, которых нет на посадочной
- [ ] Быстрые ссылки (до 8), уточнения, организация в Яндекс Бизнесе, промоакция/цены, если есть
- [ ] UTM с `{campaign_id}`, `{ad_id}`, `{keyword}`, `{match_type}`, `{source_type}`

**Закон** (`legal-and-moderation.md`)
- [ ] Тематика разрешена; нет формулировок про VPN/обход блокировок
- [ ] Предупреждения зашиты в картинки и видео, если тематика требует
- [ ] Данные рекламодателя / атрибуты договора для маркировки заполнены
- [ ] Нет товарного знака конкурента в тексте

**Стратегия**
- [ ] Без истории – «Максимум конверсий» с оплатой за клики (или «Максимум кликов»), не оплата за конверсии
- [ ] Цель обучения – денежная или ближайшая к деньгам из тех, что набирают 10/нед
- [ ] Смета показана клиенту, получено «да»

## После запуска

**Первые 1–3 дня**
- [ ] Объявления прошли модерацию (статус ACCEPTED/ON), группы не в «мало показов»
- [ ] Показы и клики идут; клики видны в Метрике, UTM доходят
- [ ] Интерфейс: нет плашки «У некоторых групп есть проблемы»
- [ ] Ничего не отключаем – данных нет

**Первая неделя**
- [ ] Отчёт по запросам → минус-фразы; разрез ключи/автотаргетинг
- [ ] Площадки РСЯ: явный фрод – в бан; остальное – по окну ≥ 7 дней
- [ ] Стратегию не трогаем – идёт обучение (1–2 недели)

**Первый месяц**
- [ ] ≥ 100 кликов на группу – первые выводы по группам и объявлениям
- [ ] A/B картинок: решение при ≥ 3 000 показов на вариант
- [ ] Если 10+ конверсий в неделю стабильно две недели – можно обсуждать оплату за конверсии
- [ ] Сверка с CRM: какие кампании приносят продажи, а не только заявки
