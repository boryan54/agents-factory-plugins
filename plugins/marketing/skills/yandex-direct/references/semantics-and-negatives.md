# Семантика, операторы, минус-фразы, автотаргетинг

## 1. Как Директ сопоставляет запросы (2026)

На Поиске два вида соответствия:
- **пословное** – запрос содержит ключевую фразу целиком;
- **семантическое** – опечатки, синонимы, более конкретные слова, переформулировки. Ключевые фразы
  не имеют приоритета перед семантическим соответствием.

Плюс **автотаргетинг** – Яндекс сам подбирает запросы по тексту объявления и сайту (см. раздел 4).
Поэтому отчёт по поисковым запросам – главный документ директолога, его читают еженедельно.

## 2. Операторы

| Оператор | Что делает | Пример и что НЕ покажется |
|---|---|---|
| без операторов | фраза в запросе + семантика | `купить диван` |
| `"…"` | фиксирует **количество слов** (без дополнительных), порядок и формы любые | `"купить диван"` – нет показа по «купить красный диван», есть по «диван купить» |
| `!` | фиксирует **форму одного слова** | `купить !диван` – нет показа по «купить диваны» |
| `+` | учитывает стоп-слово | `билеты +на поезд` |
| `[…]` | фиксирует **порядок слов** (формы и стоп-слова учитываются) | `[москва санкт-петербург] авиабилеты` |
| `(а\|б)` | группировка вариантов | `купить (диван\|кресло)` |
| `-` | минус-слово / минус-фраза | `диван -бесплатно` |

Операторы – точечный инструмент: `[дома на !воде]`, `купить !кия`. Массовые кавычки на всех фразах
режут охват. Кавычки хороши для коротких дорогих ключей, где «лишнее» слово почти всегда мусор.

## 3. Минус-слова и минус-фразы

**Как работает**
- Одиночное минус-слово отсекает **все его словоформы**. `-картинки` уберёт и «картинка», и «картинку»,
  и убьёт ваш ключ «нейросеть для картинки».
- Минус-фраза блокирует показ, только если в запросе есть **все** её слова.
- Минус-фраза, которая **целиком входит в ключевую фразу**, молча игнорируется.
- В минус-фразах работают `"…"`, `[…]`, `!`, `+`. Чтобы исключить одну форму – `-!слово`.
- Если словоформа уже есть в списке, новая молча отбрасывается. После добавления – перечитать список и
  сравнить поштучно, а не по счётчику.

**Лимиты:** кампания – 20 000 символов без пробелов; группа – 4 096 символов (вместе с ключами); не больше
7 слов в минус-фразе. Общих минус-слов на аккаунт нет: есть **библиотека наборов минус-фраз** – до 30
наборов по 4 096 символов, до 3 наборов на кампанию или группу (API: `NegativeKeywordSharedSets`).

**Правила агента**
1. Сначала отчёт по запросам, потом минусы. Никаких «универсальных» списков вслепую.
2. Минусовать **фразами**; одиночное слово – только если оно в этой нише всегда мусор.
3. Перед добавлением проверить, не пересекается ли минус-слово со словами ваших ключевых фраз
   (в любой форме).
4. Кандидат в минус – запрос с кликами без конверсий, но решение по окну **30 дней** и не по названиям
   своих продуктов/брендов.
5. Недельный объём на типовом проекте – 5–15 новых минус-фраз. Если нужно больше, проблема не в минусах,
   а в автотаргетинге или слишком широких ключах.

**Стартовые кандидаты (проверить на нишу, не ставить все подряд):**
```
вакансии · работа в · зарплата · резюме · курсовая · реферат · диплом · скачать торрент
своими руками · самостоятельно · бесплатно (если нет бесплатного предложения) · б/у (если продаём новое)
авито · юла (если не продаём там) · википедия · что такое (для горячих кампаний)
```
Опасные для «универсального» списка слова: `видео`, `инструкция`, `отзывы`, `обзор`, `схема`, `фото` –
в одних нишах мусор, в других лучшие запросы.

## 4. Автотаргетинг

**Факты (справка 2026):** в ЕПК с показами на Поиске и Картах обязателен, полностью не выключается,
не больше одного на группу. Категории: целевые, узкие, широкие, альтернативные, сопутствующие. Отдельно –
упоминание брендов: свой бренд, бренды конкурентов, без брендов. Категории между собой – «ИЛИ»,
бренды между собой – «ИЛИ», категории и бренды – «И». Изменения применяются до суток.

**Старт:** «целевые» + «свой бренд». В кампании по конкурентам – плюс «бренды конкурентов».
Остальное включать по данным.

**Ловушки**
- Группа, созданная через API, получает **все** категории включёнными. При переключении кампании с РСЯ
  на Поиск – тоже. Сразу после создания сузить и перечитать.
- Снятая галка «без упоминания брендов» может убить группы с запросами, которые Яндекс не распознаёт как
  бренд (новые продукты, транслит, латиница). API покажет всё зелёным – смотреть показы через 2–3 дня.
- Минус-фразы действуют на автотаргетинг слабо. Рычаг – категории.
- Охват автотаргетинга определяют первый заголовок, текст и категории; второй заголовок, быстрые ссылки
  и уточнения не учитываются. Заголовок группы – конкретный, «одна группа = одно свойство продукта».

**Контроль:** еженедельно разрез расхода по `CriterionType` (ключи / автотаргетинг / ретаргетинг) и по
категориям запросов (`TargetingCategory` в отчёте по запросам). Категорию выключать при расходе
≥ 2 × целевой CPA без конверсий или ≥ 5 000 ₽ при конверсии < 0,5 %. Её запросы – сразу в минус-фразы.

**Как устроено в API** – см. `api-cookbook.md`, раздел «Автотаргетинг».

## 5. Кластеризация

- Группа = один смысл запроса: «купить кухню» и «кухня на заказ» – разные группы.
- 5–15 фраз на кластер; до 200 фраз в группе (лимит), до 7 слов в фразе.
- Название группы: `[Продукт] – [намерение] – [гео]`.
- После каждого сужения смотреть, куда перетёк бюджет: утечка кочует в соседнюю самую широкую группу.
