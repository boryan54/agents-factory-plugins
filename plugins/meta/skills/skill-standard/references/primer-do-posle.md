# Пример «до / после» — один скилл, две судьбы

Скилл дайджеста новостей: слева — «на коленке», справа — пересобранный по 7-элементной схеме (см. `../SKILL.md`). Содержание то же — вся разница в структуре.

## ❌ ДО

```markdown
---
name: news-digest
description: "Скилл для новостей"
---
# Дайджест новостей
Ты — опытный аналитик с многолетним стажем. Работай качественно и внимательно.
Собери самые важные новости по теме ИИ. Оформи красиво. Не забудь про источники.
```

Что сломано: описание без триггеров (скилл будет спать) · нет источника истины (агент выдумает) · нет шагов (каша пожеланий) · пустые команды («опытный аналитик», «качественно») · нет критериев · нет эталона · нет петли.

## ✅ ПОСЛЕ

```markdown
---
name: news-digest
description: "Утренний дайджест ИИ-новостей из notes/news/ за 24 часа.
  Триггеры: 'дайджест', 'что нового', 'новости ИИ'.
  НЕ применять для: одной конкретной новости, других тем, аналитики глубже суток."
---
# Утренний дайджест ИИ-новостей

## Источник истины
Заметки в `notes/news/` за 24 часа. Нет заметок — «За сутки новых материалов нет», не выдумывать.

## Шаги
1. Собери заметки за 24 часа
2. Отбрось дубли (одна новость = один пункт, источники объедини)
3. Максимум 7 пунктов; приоритет: релизы > исследования > мнения
4. На пункт: 1 строка сути + 1-2 строки «что меняет» + ссылка
5. Сверь с эталоном; отправь; спроси «что убрать/добавить?» → в feedback.md

## Критерии
- ✅ ≤7 пунктов, каждый со ссылкой
- ✅ У каждого «что это меняет» — практический смысл
- ❌ Пункт без ссылки / общие слова «вышло обновление» без сути / дубль вчерашнего

## Эталон
Вход: 12 заметок, 3 про один релиз. Выход:
> **Anthropic выпустила Sonnet 5 — $2/$10 за млн токенов.**
> В 2,5 раза дешевле Opus при отставании 2-6%: рутину агентов можно переводить уже сейчас. [ссылка]

## Обратная связь
Ответы на «что убрать/добавить» копятся в feedback.md. Раз в неделю пересмотри правила отбора в шаге 3.
```

**Разница:** «до» — пожелание, притворяющееся инструкцией (агент каждый раз гадает). «После» — техзадание: откуда взять, как отобрать, как оформить, как проверить себя, как стать лучше. Не нужен гений — нужна схема.
