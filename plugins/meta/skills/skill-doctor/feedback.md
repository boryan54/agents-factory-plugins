# Журнал скилла — skill-doctor

Проколы, удачи и замечания из применений. По накопленному скилл обновляется
(правка под конкретный прокол, а не переписывание целиком).

Формат записи:
```
### <YYYY-MM-DD> · <проект/прогон> · [+ удача | - прокол | ? замечание]
Что произошло. Что сработало/не сработало. Предложение к правке скилла.
Источник: <Гермес / Аргус / Boris>
```
